## 规矩（每片都适用）

1. **设计是合同**。每片开工只读该片「范围」列出的几节，加上 `docs/dev/` 里对应的部分，不必通读。每个文件开头用一行注明实现的是设计哪一节。写代码时偏离了设计，在同一次改动里改设计；和业务口径冲突的，先改 `2_landed`（AGENTS.md「落盘文档目录规范」）。
2. **一样东西只有一份**。润色规则的初始版本只在 `2_landed/domestic/ai_polish.md`「润色规则（初始版本）」（`landed.py` 解析）；四个错误代码与文案只在 `turn/errors.py`，与 `ai_polish_api.md` 逐字一致。实测工具 `scripts/polish_spike/polish_core.py` 是做法 A 的过渡代码：P1–P3 每片把对应部分移进 `src` 后，工具改成 import `src`，不留两份（设计 §15 末段）。
3. **照实测过的写**。`polish_core.py` 已照设计 §5–§10 实现、过了两轮内网实测，移进 `src` 时逻辑照搬，只改结构（拆文件、类型、常量名 `POLISH_PROMPT_VERSION`）。要改逻辑的，先想清楚会不会让 r2 的结果失效；会的，请开发者重跑 `--parts cases`。
4. **SDK 不臆造**。签名以 `docs/dev/02` 和 `.venv` 里的源码为准；拿不准的写不连库的脚本实测，结论写回设计并注明版本。
5. **不碰真实数据**。单测用假 `ctx`（`tests/fakes.py`）与编写的数据；样例单号用 99 年号。要在内网或测试环境验的，写成命令交开发者执行，只回汇总与断言结果。
6. **查询助手的行为不能变**。不带 `ext_param`（或带别的任务码）的轮次与现在逐字一致；现有单测与 golden 116 条不改期望（P0 的槽位清单改为 8 个除外）。
7. **不提交、不打 tag**。开发者说「整理提交」时再提交；发预发布包由开发者做（`docs/dev/08`）。

## 容易踩的坑

| 坑 | 出处 |
|---|---|
| `await asyncio.wait_for(...)` 期间生成器发不出进度事件；停止时生成器收到的是 `GeneratorExit` 不是 `CancelledError`，收尾放 `finally`；异步生成器不能 `return` 值 | 设计 §4 第 ⑥ 步、§17 第 1 条 |
| 只能有一条 system，且放在最前；平台红线段由 `ctx.llm` 并进去，提示里不重复 | `docs/dev/02`「本地模型客户端」 |
| `ctx.llm` 客户端超时固定 120 秒，`CALL_TIMEOUT` 110 秒要在它之内 | 设计 §4 |
| `require_privileges=True` 在 `describe()` 时也检查：润色分支不调 `describe()`，按编号取数被拒按「查不到」处理 | 设计 §2.3 |
| 字数上限：页面给了就用页面的，不与栏目默认取较小的一个 | 设计 §5 |
| 判长、判空、长度比、日志 `input_chars` 都是「去掉占位标记与空白后的字数」 | 设计 §6.1、§14 |
| 纯文字栏的字数预算：段落标记按 1 个换行算，不是 7 个字符 | 设计 §6.2 |
| `polish/` 不 import `plan`、`present`、`skills`、`stats`；`html` 标准库可以用（只有沙箱脚本不许） | 设计 §1.2、§2.4 |
| `landed.py` 在导入时解析 `2_landed`：改了「润色规则（初始版本）」的标题或表头，模块导入即失败 | 查询设计 §11；设计 §10 |
| `tests/fakes.py::run()` 不带 `inputs`，润色的单测自己建 `ModuleRequest(inputs={"ext_param": …})`；假模型按 `POLISH_MARKER` 认这次调用 | 设计 §8.2、§12.1 |
| `FakeLLM` 没准备回放时抛的 `AssertionError` 会被润色的 `except Exception` 吞掉，单测按调用次数与事件断言，不靠这个报错 | `tests/fakes.py` |
| 本机沙箱偶发 `exit=3221227274`，整跑偶尔有一条答「这一部分暂时没查到」：先单跑那条，复现了才查（润色不进沙箱，碰到的只会是查询助手的用例） | 查询设计 §19 |
| Windows 控制台是 GBK，脚本打印中文与 ✓ 会乱码或报 `UnicodeEncodeError`：看输出文件，或设 `PYTHONIOENCODING=utf-8` | 2026-11-10 实测 |
| `scripts/qa_test.py` 在 P6 之前不转发 `ext_param`（带了也被静默丢掉）；P6 起转发，旧版本的脚本不要拿来跑 polish 样例 | 设计 §12.2 |
| 本机 `forge dev serve` 要 `uv run --with greenlet forge dev serve` 才起得来（平台依赖缺 greenlet）；没配 `FORGE_LLM_BASE_URL` 时润色到调模型就答 `POLISH_FAILED`（日志 `llm_unavailable`），通道本身照样能验 | 2026-11-11 P6 实测 |
