# 2026-10-27 处理步骤内容人名前缀探测说明

国内、海外处理步骤的「内容」是系统拼的一句话，开头是操作人姓名，如「张三，需要设计变更，责任人：李四，……」（见两张处理步骤表的字段说明）。按文字找单时，治理任务把分析类环节的内容整理进比对文字，要先去掉开头的人名，否则按人名或常见字能误命中，按意思找也会被姓名干扰。G2 决策把具体去法留给 G4a；G4a 设计稿（决策 2026-10-27「模块技术设计」§12）拟的规则是：

> 内容以本条操作人姓名开头、后跟「，」「,」「：」「:」「、」或空白时，去掉姓名与这一个分隔符；其余不动。内容已包含意见时只留内容，否则意见与内容都留。

本说明数一数这条规则能覆盖多少条记录，以及「内容含意见」有多常见。结果只影响治理任务的清洗写法，不改 mart 表结构。

**执行状态**：W1、W1b 都已于 2026-10-27 执行完（业务方 2026-10-27 正式镜像计数）。

| 段 | 结论 | 去向 |
|---|---|---|
| W1 | 国内分析类环节 4,299 条，内容为空 166 条；非空的 4,133 条里 4,125 条以操作人姓名开头，姓名在中间 3 条（预防对策确认）、不含姓名 5 条（SQE跟进 1 条、工厂制程分析 4 条）；操作人都查得到。海外 19 条全部以姓名开头。内容含意见：SQE跟进、设计变更、IQC填写意见、工厂制程分析、预防对策确认几乎全含；国内责任人确认、工程确认有意见的 235 条里只有 1 条被内容包含 | 「去掉姓名」不再要求后面是分隔符；「内容含意见时只留内容，否则两样都留」不变 |
| W1b | 姓名后第一个字符：逗号（半角 1,673、全角 1,611）最多；「确」828 条（国内 819、海外 9，都是责任人确认）、「预」24 条（预防对策确认）、括号 8 条 | 同上：只要以姓名开头就去掉姓名，后面是分隔符时连分隔符一起去掉 |

## W1 各环节内容的开头是什么（镜像库，可发回）

先剥掉内容与意见里的 HTML 标签，再按操作人姓名比较。

```sql
WITH s AS (
    SELECT '国内' AS "域", l."Step"::int::text AS "环节",
           btrim(regexp_replace(coalesce(l."Measures", ''), '<[^>]+>', '', 'g')) AS m,
           btrim(regexp_replace(coalesce(l."Opinon", ''), '<[^>]+>', '', 'g')) AS o,
           e."Name" AS n
    FROM "ZCTracking_ProblemSteplog" l
    JOIN "ZCTracking_ProblemList" p ON p."ID" = l."ProblemId" AND coalesce(p."IsDelete"::int, 0) = 0
    LEFT JOIN "Employee" e ON e."ID" = l."AddUser"
    WHERE l."Step"::int IN (3, 4, 6, 10, 11, 13, 14, 35)
    UNION ALL
    SELECT '海外', l."StepStr",
           btrim(regexp_replace(coalesce(l."Measures", ''), '<[^>]+>', '', 'g')),
           btrim(regexp_replace(coalesce(l."Opinon", ''), '<[^>]+>', '', 'g')),
           e."Name"
    FROM "OverseasProblem_StepLog" l
    JOIN "OverseasProblemDetail" p ON p."Id" = l."ProblemId" AND p."IsDelete"::int = 0
    LEFT JOIN "Employee" e ON e."ID" = l."AddUser"
    WHERE l."StepStr" IN ('SQE跟进', 'IQC意见', 'IQC填写意见', '工厂制程分析', '责任人确认', '工程确认',
                          '设计变更', '设计变更后SQE确认', '预防对策确认')
)
SELECT "域", "环节",
       count(*) AS "条数",
       count(*) FILTER (WHERE m = '') AS "内容为空",
       count(*) FILTER (WHERE n IS NULL) AS "操作人查不到",
       count(*) FILTER (WHERE n IS NOT NULL AND m <> '' AND left(m, length(n)) = n
                        AND substr(m, length(n) + 1, 1) IN ('，', ',', '：', ':', '、', ' ', '　')) AS "姓名加分隔符开头",
       count(*) FILTER (WHERE n IS NOT NULL AND m = n) AS "内容只有姓名",
       count(*) FILTER (WHERE n IS NOT NULL AND m <> n AND left(m, length(n)) = n
                        AND substr(m, length(n) + 1, 1) NOT IN ('，', ',', '：', ':', '、', ' ', '　')) AS "姓名开头但后面不是分隔符",
       count(*) FILTER (WHERE n IS NOT NULL AND m <> '' AND left(m, length(n)) <> n AND position(n IN m) > 0) AS "姓名在中间",
       count(*) FILTER (WHERE n IS NOT NULL AND m <> '' AND position(n IN m) = 0) AS "不含姓名",
       count(*) FILTER (WHERE o <> '' AND m <> '' AND position(o IN m) > 0) AS "内容含意见",
       count(*) FILTER (WHERE o <> '' AND m <> '' AND position(o IN m) = 0) AS "内容不含意见"
FROM s
GROUP BY 1, 2
ORDER BY 1, 2;
```

## W1b 姓名后面紧跟的是什么字符（镜像库，可发回）

只看以操作人姓名开头的记录，数姓名后第一个字符，各域取最多的 15 种。

```sql
WITH s AS (
    SELECT '国内' AS "域",
           btrim(regexp_replace(coalesce(l."Measures", ''), '<[^>]+>', '', 'g')) AS m, e."Name" AS n
    FROM "ZCTracking_ProblemSteplog" l
    JOIN "ZCTracking_ProblemList" p ON p."ID" = l."ProblemId" AND coalesce(p."IsDelete"::int, 0) = 0
    JOIN "Employee" e ON e."ID" = l."AddUser"
    WHERE l."Step"::int IN (3, 4, 6, 10, 11, 13, 14, 35)
    UNION ALL
    SELECT '海外', btrim(regexp_replace(coalesce(l."Measures", ''), '<[^>]+>', '', 'g')), e."Name"
    FROM "OverseasProblem_StepLog" l
    JOIN "OverseasProblemDetail" p ON p."Id" = l."ProblemId" AND p."IsDelete"::int = 0
    JOIN "Employee" e ON e."ID" = l."AddUser"
    WHERE l."StepStr" IN ('SQE跟进', 'IQC意见', 'IQC填写意见', '工厂制程分析', '责任人确认', '工程确认',
                          '设计变更', '设计变更后SQE确认', '预防对策确认')
),
c AS (
    SELECT "域", CASE WHEN m = n THEN '（结尾）' ELSE substr(m, length(n) + 1, 1) END AS "后一个字符",
           count(*) AS "条数"
    FROM s
    WHERE left(m, length(n)) = n
    GROUP BY 1, 2
),
r AS (SELECT c.*, row_number() OVER (PARTITION BY "域" ORDER BY "条数" DESC) AS rn FROM c)
SELECT "域", "后一个字符", "条数" FROM r WHERE rn <= 15 ORDER BY 1, 3 DESC;
```

## 结果怎么用

| 结果 | 怎么处理 |
|---|---|
| 「姓名加分隔符开头」占非空内容的绝大多数，W1b 里也只有这几种分隔符 | 规则不变，G4b 照设计稿写 |
| W1b 里还有别的分隔符（如「-」「。」） | 加进分隔符清单 |
| 「姓名开头但后面不是分隔符」不少 | 看 W1b 里排前面的字符，判断是不是姓名直接连着内容；是的话改为只要以姓名开头就去掉姓名 |
| 「姓名在中间」「不含姓名」不少 | 这些环节的内容不是「姓名 + 内容」的形状，不去前缀，照原样整理；在设计稿里写明是哪些环节 |
| 「内容不含意见」不少 | 意见与内容都留（设计稿现行规则），不用改 |
| 「操作人查不到」不少 | 这些记录不去前缀，治理任务统计行里报出条数 |
