# 制程问题查询助手 比对范围扩充探测说明（2026-10-20）

> 给谁：能连到正式环境镜像库（PostgreSQL，库名 `ai-info`）的业务方。
> 做什么：`docs/open-questions.md` G29 提议把改善建议、预防对策、处理步骤等文字加进「按文字找单」的比对范围。本说明给出只读查询，看这些文字填得多不多、是不是实在内容、和主表重复多少，结果用于 G29 的细则与 `docs/decisions/2026-10-20-G2数据源与治理决策.md` 的分段规模。

## 执行须知

- 全部在镜像库上执行：连到 `ai-info` 库，默认 schema 为 `public`，SQL 里只写表名。表名、列名保留源表大小写（P0a 已核实），删除标记一律 `::int` 后比较。
- 全部是只读 `SELECT`。E1–E4 只输出计数与字符数；E2 另输出处理环节名称。**E5 会输出高频短写法的原文**（如「同意」「OK」），外传前请人工逐行过目，删掉含人名、单号、料号、供应商名或其他具体业务内容的行（E5 只列出现至少 5 次的写法，正常情况下都是套话）。
- 「剥净」与 mart 的清洗一致：去掉内嵌图片、HTML 标签与实体，连续空白压成一个空格。「字数」按剥净后去掉空格的字符数算。
- 「实质文字」指剥净后超过 10 个字。10 字是暂定门槛，E5 的结果用来校准。
- 只看未删除的单（国内是否删除不为 1；巴西状态不为 -1；海外是否删除为 0）。
- 巴西问题描述里有单值约 4,800 万字的内嵌图片，E1 会慢一些，属正常。
- **交付**：每段结果另存为 CSV，按小节编号命名（如 `E1.csv`），放到 `docs/1_user_input/answers/<执行日期>/`。某段报错时，把报错信息原样存成同名文本，其余照常执行。

## 总览

| 编号 | 核实什么 | 用于判定 |
|---|---|---|
| E1 | 三域主表各叙述字段（含候选字段）按问题类型的填写情况与字数 | 改善建议、预防对策、海外改善措施、巴西预防对策值不值得加；各问题类型主要把内容写在哪 |
| E2 | 国内、海外处理步骤按环节、按列的填写情况、短文字占比 | 哪些环节、哪几列是实在内容，哪些是套话 |
| E3 | 主表原因、措施没写实在内容，但处理步骤里有的单有多少 | 处理步骤进比对范围能多找到多少单 |
| E4 | 处理步骤文字在同单内重复、与主表重复的比例；去重后的字数与段数估算 | 清洗规则；向量规模 |
| E5 | 高频短写法（套话）原文 | 套话门槛与过滤清单 |

## E1 主表叙述字段的填写情况（镜像库）

每域、每个问题类型、每个字段一行，另有「（全部）」一行是本域合计。巴西取最新一条处理过程（`ID` 最大），与比对范围的取法一致。

```sql
WITH src AS (
    SELECT '国内' AS "域",
        CASE m."ProblemType"::int
             WHEN 1 THEN '硬件问题' WHEN 2 THEN '软件问题' WHEN 3 THEN '物料问题'
             WHEN 4 THEN '资料问题' WHEN 5 THEN '工厂制程' WHEN 6 THEN '结构问题'
             WHEN 7 THEN '制程优化' ELSE '其他（未识别）' END AS "问题类型",
        c."字段", c.x
    FROM "ZCTracking_ProblemList" m
    CROSS JOIN LATERAL (VALUES
        ('问题描述', m."ProblemDesc"::text),
        ('原因分析', m."Reason"::text),
        ('改善建议', m."Improve"::text),
        ('改善措施', m."Measures"::text),
        ('预防对策', m."Prevention"::text)
    ) AS c("字段", x)
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT '巴西',
        COALESCE(NULLIF(btrim(split_part(b."ProblemType"::text, '|', 1)), ''), '未填'),
        c."字段", c.x
    FROM "BrazilProblemList" b
    LEFT JOIN LATERAL (SELECT p."DisposeResult", p."ReasonAnalysis",
                              p."ImprovementMeasure", p."PrecautionPolicy"
                       FROM "BrazilProblemProcess" p
                       WHERE p."ProblemID" = b."ID"
                       ORDER BY p."ID" DESC
                       LIMIT 1) lp ON true
    CROSS JOIN LATERAL (VALUES
        ('问题描述',                 b."ProblemDesc"::text),
        ('最新处理过程.SQE跟进结果', lp."DisposeResult"::text),
        ('最新处理过程.原因分析',    lp."ReasonAnalysis"::text),
        ('最新处理过程.改善措施',    lp."ImprovementMeasure"::text),
        ('最新处理过程.预防对策',    lp."PrecautionPolicy"::text)
    ) AS c("字段", x)
    WHERE b."Status"::int <> -1
    UNION ALL
    SELECT '海外',
        CASE WHEN o."ProblemType" IS NULL THEN '未填'
             WHEN o."ProblemType"::int = 1 THEN '硬件问题' WHEN o."ProblemType"::int = 2 THEN '软件问题'
             WHEN o."ProblemType"::int = 3 THEN '物料问题' WHEN o."ProblemType"::int = 4 THEN '其他'
             WHEN o."ProblemType"::int = 5 THEN '工厂制程' WHEN o."ProblemType"::int = 6 THEN '结构问题'
             WHEN o."ProblemType"::int = 7 THEN '制程优化' ELSE '其他（未识别）' END,
        c."字段", c.x
    FROM "OverseasProblemDetail" o
    CROSS JOIN LATERAL (VALUES
        ('问题描述', o."ProblemDesc"::text),
        ('问题原因', o."Reason"::text),
        ('改善建议', o."Improve"::text),
        ('改善措施', o."Measures"::text),
        ('预防对策', o."Prevention"::text)
    ) AS c("字段", x)
    WHERE COALESCE(o."IsDelete"::int, 0) = 0
), cl AS (
    SELECT "域", "问题类型", "字段",
        NULLIF(btrim(x), '') IS NOT NULL AS has_raw,
        char_length(replace(z.t, ' ', '')) AS n
    FROM src
    CROSS JOIN LATERAL (SELECT btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')) AS t) z
)
SELECT "域", COALESCE("问题类型", '（全部）') AS "问题类型", "字段",
    count(*)                                   AS "未删除单数",
    count(*) FILTER (WHERE has_raw)            AS "原文有值单数",
    count(*) FILTER (WHERE n > 0)              AS "剥净后有字单数",
    count(*) FILTER (WHERE n > 10)             AS "实质文字单数",
    count(*) FILTER (WHERE n BETWEEN 1 AND 10) AS "1至10字",
    count(*) FILTER (WHERE n BETWEEN 11 AND 50)  AS "11至50字",
    count(*) FILTER (WHERE n BETWEEN 51 AND 200) AS "51至200字",
    count(*) FILTER (WHERE n BETWEEN 201 AND 500) AS "201至500字",
    count(*) FILTER (WHERE n > 500)            AS "500字以上",
    sum(n)                                     AS "剥净后字数合计",
    max(n)                                     AS "最长"
FROM cl
GROUP BY GROUPING SETS (("域", "字段", "问题类型"), ("域", "字段"))
ORDER BY "域", "字段", GROUPING("问题类型") DESC, "问题类型";
```

## E2 处理步骤按环节的填写情况（镜像库）

国内、海外处理步骤，每个环节、每列一行。「不同写法数」是实质文字去重后的条数，远小于「实质文字行数」说明该环节多是固定写法。环节名称是系统里的步骤名，不是业务数据，但外传前请顺带过目。

```sql
WITH s AS (
    SELECT '国内' AS "域", COALESCE(NULLIF(btrim(s."StepStr"::text), ''), '（未填）') AS "处理环节",
        s."ProblemId" AS pid, c."列", c.x
    FROM "ZCTracking_ProblemSteplog" s
    JOIN "ZCTracking_ProblemList" m ON m."ID" = s."ProblemId"
    CROSS JOIN LATERAL (VALUES
        ('结论', s."Result"::text),
        ('意见', s."Opinon"::text),
        ('措施', s."Measures"::text)
    ) AS c("列", x)
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT '海外', COALESCE(NULLIF(btrim(s."StepStr"::text), ''), '（未填）'),
        s."ProblemId", c."列", c.x
    FROM "OverseasProblem_StepLog" s
    JOIN "OverseasProblemDetail" o ON o."Id" = s."ProblemId"
    CROSS JOIN LATERAL (VALUES
        ('结论',     s."Result"::text),
        ('意见',     s."Opinon"::text),
        ('预防措施', s."Measures"::text)
    ) AS c("列", x)
    WHERE COALESCE(o."IsDelete"::int, 0) = 0
), cl AS (
    SELECT "域", "处理环节", "列", pid, z.t,
        char_length(replace(z.t, ' ', '')) AS n
    FROM s
    CROSS JOIN LATERAL (SELECT btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')) AS t) z
)
SELECT "域", "处理环节", "列",
    count(*)                                   AS "步骤记录数",
    count(DISTINCT pid)                        AS "涉及单数",
    count(*) FILTER (WHERE n > 0)              AS "剥净后有字行数",
    count(*) FILTER (WHERE n BETWEEN 1 AND 10) AS "1至10字行数",
    count(*) FILTER (WHERE n > 10)             AS "实质文字行数",
    count(DISTINCT t) FILTER (WHERE n > 10)    AS "实质文字不同写法数",
    count(DISTINCT pid) FILTER (WHERE n > 10)  AS "有实质文字的单数",
    sum(n)                                     AS "剥净后字数合计",
    max(n)                                     AS "最长"
FROM cl
GROUP BY "域", "处理环节", "列"
ORDER BY "域", "处理环节", "列";
```

## E3 主表没写、处理步骤里写了的单（镜像库）

国内、海外。按主表四个字段（原因分析或问题原因、改善建议、改善措施、预防对策）有没有实质文字把单分成三类；再看这些单的处理步骤里有没有「新内容」：实质文字，且不与本单主表任一叙述字段（含问题描述）相同、也不被它包含。

```sql
WITH m AS (
    SELECT '国内' AS "域",
        CASE m."ProblemType"::int
             WHEN 1 THEN '硬件问题' WHEN 2 THEN '软件问题' WHEN 3 THEN '物料问题'
             WHEN 4 THEN '资料问题' WHEN 5 THEN '工厂制程' WHEN 6 THEN '结构问题'
             WHEN 7 THEN '制程优化' ELSE '其他（未识别）' END AS "问题类型",
        m."ID" AS pid,
        m."ProblemDesc"::text AS d, m."Reason"::text AS r, m."Improve"::text AS i,
        m."Measures"::text AS me, m."Prevention"::text AS pv
    FROM "ZCTracking_ProblemList" m
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT '海外',
        CASE WHEN o."ProblemType" IS NULL THEN '未填'
             WHEN o."ProblemType"::int = 1 THEN '硬件问题' WHEN o."ProblemType"::int = 2 THEN '软件问题'
             WHEN o."ProblemType"::int = 3 THEN '物料问题' WHEN o."ProblemType"::int = 4 THEN '其他'
             WHEN o."ProblemType"::int = 5 THEN '工厂制程' WHEN o."ProblemType"::int = 6 THEN '结构问题'
             WHEN o."ProblemType"::int = 7 THEN '制程优化' ELSE '其他（未识别）' END,
        o."Id", o."ProblemDesc"::text, o."Reason"::text, o."Improve"::text,
        o."Measures"::text, o."Prevention"::text
    FROM "OverseasProblemDetail" o
    WHERE COALESCE(o."IsDelete"::int, 0) = 0
), mc AS (
    SELECT m."域", m."问题类型", m.pid, f.k, z.t, char_length(replace(z.t, ' ', '')) AS n
    FROM m
    CROSS JOIN LATERAL (VALUES ('d', m.d), ('r', m.r), ('i', m.i), ('me', m.me), ('pv', m.pv)) AS f(k, x)
    CROSS JOIN LATERAL (SELECT btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(f.x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')) AS t) z
), mo AS (
    SELECT "域", "问题类型", pid,
        string_agg(t, ' | ') AS main_all,
        bool_or(k IN ('r', 'me') AND n > 10)            AS has_rm,
        bool_or(k IN ('r', 'i', 'me', 'pv') AND n > 10) AS has_rimp
    FROM mc
    GROUP BY "域", "问题类型", pid
), st AS (
    SELECT '国内' AS "域", s."ProblemId" AS pid, c.x
    FROM "ZCTracking_ProblemSteplog" s
    CROSS JOIN LATERAL (VALUES (s."Result"::text), (s."Opinon"::text), (s."Measures"::text)) AS c(x)
    UNION ALL
    SELECT '海外', s."ProblemId", c.x
    FROM "OverseasProblem_StepLog" s
    CROSS JOIN LATERAL (VALUES (s."Result"::text), (s."Opinon"::text), (s."Measures"::text)) AS c(x)
), sc AS (
    SELECT st."域", st.pid, z.t, char_length(replace(z.t, ' ', '')) AS n
    FROM st
    CROSS JOIN LATERAL (SELECT btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(st.x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')) AS t) z
), sn AS (
    SELECT u."域", u.pid, sum(char_length(replace(u.t, ' ', ''))) AS new_chars
    FROM (SELECT DISTINCT sc."域", sc.pid, sc.t
          FROM sc
          JOIN mo ON mo."域" = sc."域" AND mo.pid = sc.pid
          WHERE sc.n > 10 AND strpos(mo.main_all, sc.t) = 0) u
    GROUP BY u."域", u.pid
), cat AS (
    SELECT mo."域", mo."问题类型",
        CASE WHEN NOT mo.has_rimp THEN '1 四个字段都没有实质文字'
             WHEN NOT mo.has_rm   THEN '2 原因、措施没有，建议或对策有'
             ELSE '3 原因或措施有' END AS "主表情况",
        sn.new_chars
    FROM mo
    LEFT JOIN sn ON sn."域" = mo."域" AND sn.pid = mo.pid
)
SELECT "域", COALESCE("问题类型", '（全部）') AS "问题类型", "主表情况",
    count(*)                                   AS "单数",
    count(new_chars)                           AS "处理步骤有新内容的单数",
    count(*) FILTER (WHERE new_chars > 30)     AS "新内容超过30字的单数",
    COALESCE(sum(new_chars), 0)                AS "新内容字数合计"
FROM cat
GROUP BY GROUPING SETS (("域", "主表情况", "问题类型"), ("域", "主表情况"))
ORDER BY "域", "主表情况", GROUPING("问题类型") DESC, "问题类型";
```

「问题类型」为「（全部）」的行是本域在该主表情况下的合计。

## E4 处理步骤文字的重复与规模（镜像库）

国内、海外。只看实质文字的步骤记录（剥净后超过 10 字），逐条判断：

- 同单重复：同一张单里更早的步骤记录（任一列）已有完全相同的文字；
- 与主表重复：与本单主表任一叙述字段（问题描述、原因分析或问题原因、改善建议、改善措施、预防对策）相同或被它包含。

两者都不是的记录算「留下」。留下的记录按单拼成一段（每条前加环节名称和冒号），给出每单字数分档，并按每 400 字一段估算段数（每单至少 1 段）。

```sql
WITH m AS (
    SELECT '国内' AS "域", m."ID" AS pid,
        ARRAY[m."ProblemDesc"::text, m."Reason"::text, m."Improve"::text,
              m."Measures"::text, m."Prevention"::text] AS xs
    FROM "ZCTracking_ProblemList" m
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT '海外', o."Id",
        ARRAY[o."ProblemDesc"::text, o."Reason"::text, o."Improve"::text,
              o."Measures"::text, o."Prevention"::text]
    FROM "OverseasProblemDetail" o
    WHERE COALESCE(o."IsDelete"::int, 0) = 0
), mo AS (
    SELECT m."域", m.pid,
        string_agg(btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(u.x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')), ' | ') AS main_all
    FROM m
    CROSS JOIN LATERAL unnest(m.xs) AS u(x)
    GROUP BY m."域", m.pid
), st AS (
    SELECT '国内' AS "域", s."ProblemId" AS pid, s."ID" AS sid,
        COALESCE(NULLIF(btrim(s."StepStr"::text), ''), '处理步骤') AS step, c.k, c.x
    FROM "ZCTracking_ProblemSteplog" s
    CROSS JOIN LATERAL (VALUES (1, s."Result"::text), (2, s."Opinon"::text), (3, s."Measures"::text)) AS c(k, x)
    UNION ALL
    SELECT '海外', s."ProblemId", s."Id",
        COALESCE(NULLIF(btrim(s."StepStr"::text), ''), '处理步骤'), c.k, c.x
    FROM "OverseasProblem_StepLog" s
    CROSS JOIN LATERAL (VALUES (1, s."Result"::text), (2, s."Opinon"::text), (3, s."Measures"::text)) AS c(k, x)
), sc AS (
    SELECT st."域", st.pid, st.sid, st.k, st.step, z.t,
        char_length(replace(z.t, ' ', '')) AS n
    FROM st
    JOIN mo ON mo."域" = st."域" AND mo.pid = st.pid
    CROSS JOIN LATERAL (SELECT btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(st.x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')) AS t) z
), flag AS (
    SELECT sc.*,
        row_number() OVER (PARTITION BY sc."域", sc.pid, sc.t ORDER BY sc.sid, sc.k) > 1 AS dup_in_issue,
        strpos(mo.main_all, sc.t) > 0 AS dup_main
    FROM sc
    JOIN mo ON mo."域" = sc."域" AND mo.pid = sc.pid
    WHERE sc.n > 10
), per_issue AS (
    SELECT "域", pid,
        sum(n + char_length(step) + 1) AS kept_chars
    FROM flag
    WHERE NOT dup_in_issue AND NOT dup_main
    GROUP BY "域", pid
), rec AS (
    SELECT "域",
        count(*)                                                      AS "实质文字记录数",
        count(*) FILTER (WHERE dup_in_issue)                          AS "同单重复记录数",
        count(*) FILTER (WHERE NOT dup_in_issue AND dup_main)         AS "与主表重复记录数",
        count(*) FILTER (WHERE NOT dup_in_issue AND NOT dup_main)     AS "留下记录数"
    FROM flag
    GROUP BY "域"
), iss AS (
    SELECT "域",
        count(*)                                                AS "有留下文字的单数",
        sum(kept_chars)                                         AS "留下字数合计",
        count(*) FILTER (WHERE kept_chars <= 200)               AS "每单200字以内",
        count(*) FILTER (WHERE kept_chars BETWEEN 201 AND 500)  AS "每单201至500字",
        count(*) FILTER (WHERE kept_chars BETWEEN 501 AND 2000) AS "每单501至2000字",
        count(*) FILTER (WHERE kept_chars > 2000)               AS "每单2000字以上",
        max(kept_chars)                                         AS "每单最长",
        sum(GREATEST(1, ceil(kept_chars / 400.0)))::bigint      AS "估算段数"
    FROM per_issue
    GROUP BY "域"
)
SELECT rec.*, iss."有留下文字的单数", iss."留下字数合计", iss."每单200字以内", iss."每单201至500字",
    iss."每单501至2000字", iss."每单2000字以上", iss."每单最长", iss."估算段数"
FROM rec
LEFT JOIN iss ON iss."域" = rec."域"
ORDER BY rec."域";
```

## E5 高频短写法（镜像库，外传前人工过目）

处理步骤各列与候选主表字段里，剥净后 1 至 20 字、出现至少 5 次的写法，每域每列取出现次数最多的 20 个。用来定「套话」门槛与过滤清单。

**外传前请逐行过目**：删掉含人名、单号、料号、供应商名或其他具体业务内容的行，并在 `README.txt` 里注明删了几行。

```sql
WITH v AS (
    SELECT '国内' AS "域", '处理步骤.' || c.k AS "列", c.x
    FROM "ZCTracking_ProblemSteplog" s
    JOIN "ZCTracking_ProblemList" m ON m."ID" = s."ProblemId"
    CROSS JOIN LATERAL (VALUES ('结论', s."Result"::text), ('意见', s."Opinon"::text),
                               ('措施', s."Measures"::text)) AS c(k, x)
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT '国内', '主表.' || c.k, c.x
    FROM "ZCTracking_ProblemList" m
    CROSS JOIN LATERAL (VALUES ('原因分析', m."Reason"::text), ('改善建议', m."Improve"::text),
                               ('改善措施', m."Measures"::text), ('预防对策', m."Prevention"::text)) AS c(k, x)
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT '巴西', '处理过程.' || c.k, c.x
    FROM "BrazilProblemProcess" p
    JOIN "BrazilProblemList" b ON b."ID" = p."ProblemID"
    CROSS JOIN LATERAL (VALUES ('SQE跟进结果', p."DisposeResult"::text), ('原因分析', p."ReasonAnalysis"::text),
                               ('改善措施', p."ImprovementMeasure"::text), ('预防对策', p."PrecautionPolicy"::text)) AS c(k, x)
    WHERE b."Status"::int <> -1
    UNION ALL
    SELECT '海外', '处理步骤.' || c.k, c.x
    FROM "OverseasProblem_StepLog" s
    JOIN "OverseasProblemDetail" o ON o."Id" = s."ProblemId"
    CROSS JOIN LATERAL (VALUES ('结论', s."Result"::text), ('意见', s."Opinon"::text),
                               ('预防措施', s."Measures"::text)) AS c(k, x)
    WHERE COALESCE(o."IsDelete"::int, 0) = 0
    UNION ALL
    SELECT '海外', '主表.' || c.k, c.x
    FROM "OverseasProblemDetail" o
    CROSS JOIN LATERAL (VALUES ('问题原因', o."Reason"::text), ('改善建议', o."Improve"::text),
                               ('改善措施', o."Measures"::text), ('预防对策', o."Prevention"::text)) AS c(k, x)
    WHERE COALESCE(o."IsDelete"::int, 0) = 0
), cl AS (
    SELECT "域", "列", z.t, char_length(replace(z.t, ' ', '')) AS n
    FROM v
    CROSS JOIN LATERAL (SELECT btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')) AS t) z
), g AS (
    SELECT "域", "列", t AS "写法", max(n) AS "字数", count(*) AS "出现次数",
        row_number() OVER (PARTITION BY "域", "列" ORDER BY count(*) DESC, t) AS rk
    FROM cl
    WHERE n BETWEEN 1 AND 20
    GROUP BY "域", "列", t
    HAVING count(*) >= 5
)
SELECT "域", "列", rk AS "名次", "写法", "字数", "出现次数"
FROM g
WHERE rk <= 20
ORDER BY "域", "列", rk;
```
