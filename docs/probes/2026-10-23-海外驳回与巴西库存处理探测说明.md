## S1 海外处理步骤有哪些环节（O18）

```sql
WITH m AS (
    SELECT "Id" FROM "OverseasProblemDetail" WHERE COALESCE("IsDelete"::int, 0) = 0
)
SELECT btrim(st."StepStr"::text)         AS "环节名称",
       count(*)                          AS "步骤记录数",
       count(DISTINCT st."ProblemId")    AS "单数"
FROM "OverseasProblem_StepLog" st
JOIN m ON m."Id" = st."ProblemId"
GROUP BY 1
ORDER BY 3 DESC, 1;
```

## S2 巴西库存处理、供应商补料为「是」的单有多少（B22）

只看每张单最新一条处理过程，与单张单详情的取法一致。

```sql
WITH m AS (
    SELECT "ID" FROM "BrazilProblemList" WHERE "Status"::int <> -1
),
p AS (
    SELECT DISTINCT ON (pr."ProblemID")
           pr."ProblemID",
           btrim(COALESCE(pr."IsStockPrecess"::text, ''))       AS stock,
           btrim(COALESCE(pr."IsSupplementMaterial"::text, '')) AS supp
    FROM "BrazilProblemProcess" pr
    JOIN m ON m."ID" = pr."ProblemID"
    ORDER BY pr."ProblemID", pr."ID" DESC
)
SELECT '是否库存处理为「是」' AS "项", count(*) AS "单数" FROM p WHERE stock = '是'
UNION ALL SELECT '是否供应商补料为「是」', count(*) FROM p WHERE supp = '是'
UNION ALL SELECT '两项都为「是」', count(*) FROM p WHERE stock = '是' AND supp = '是';
```

## S2b 挑几张这样的巴西单（输出问题编号，只在内网用）

S2 有单时才执行。每种组合挑最近的 3 张。

```sql
WITH m AS (
    SELECT "ID", "OrderNumber" FROM "BrazilProblemList" WHERE "Status"::int <> -1
),
p AS (
    SELECT DISTINCT ON (pr."ProblemID")
           pr."ProblemID",
           pr."ID"                                              AS pid,
           btrim(COALESCE(pr."IsStockPrecess"::text, ''))       AS stock,
           btrim(COALESCE(pr."IsSupplementMaterial"::text, '')) AS supp
    FROM "BrazilProblemProcess" pr
    JOIN m ON m."ID" = pr."ProblemID"
    ORDER BY pr."ProblemID", pr."ID" DESC
),
t AS (
    SELECT m."OrderNumber", p.stock, p.supp,
           row_number() OVER (PARTITION BY p.stock = '是', p.supp = '是' ORDER BY p.pid DESC) AS rn
    FROM p
    JOIN m ON m."ID" = p."ProblemID"
    WHERE p.stock = '是' OR p.supp = '是'
)
SELECT "OrderNumber" AS "问题编号", stock AS "是否库存处理", supp AS "是否供应商补料"
FROM t
WHERE rn <= 3
ORDER BY 2 DESC, 3 DESC;
```

**结果怎么用**：
- S2 都是 0：巴西目前没有这样的单。B22 按「只给『是 / 否』，为『是』时另给对应的数量与单号」关闭，以后出现再核对页面。
- S2 有：从 S2b 各挑一张，到管理页面上看「责任人确认」里，「库存处理」「供应商补料」为「是」时后面多出了哪些栏，只回告栏目名，不要内容。
