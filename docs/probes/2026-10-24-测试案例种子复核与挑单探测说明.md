# 2026-10-24 测试案例种子复核与挑单探测说明

测试案例集（`docs/testcases/seed/`）进 G3 前要补两类数据：

- **种子复核**：工作簿「应命中集v0」里的单号取自国内种子案例集（2026-07 的记录，没有业务确认标记），镜像已到 2026-10。要逐条确认单号还在、没删除、仍满足案例条件（机型、建单时间），并按现行说法清单看命中落在哪一组。
- **挑单**：二十多条案例用的是示例单号、示例姓名，或「这单」没有具体单号，要从正式数据里挑真实的号替换。

本说明替代原来的 `docs/testcases/seed/种子命中复核.sql`。那份 SQL 在原始文字上匹配（没剥图片），处理步骤没限定分析类环节，把「卡扣」算作电池与充电，也不核对机型和时间，结果不可用。

## 执行须知

- 在正式镜像库 `ai-info` 上执行，默认 schema 为 `public`，SQL 里只写表名；表名、列名保留源表大小写，删除标记、状态一律 `::int` 后比较。T2a 另有 SQL Server 写法，镜像里没有国内工厂表时用它。
- 全部是只读 `SELECT`。
- 只看未删除的单（国内是否删除不为 1；巴西状态不为 -1；海外是否删除为 0）。T1 例外：它要查出种子单是否被删，所以不按删除标记过滤，只把「未删除」作为一列输出。
- 文字处理与说法清单命中计数探测（2026-10-22）一致：剥净内嵌图片、HTML 标签与实体，连续空白压成一个空格，全角字母数字转半角、转小写；处理步骤只取分析类环节（编码 3、4、6、10、11、13、14、35），每个编码只取最新一条。T1 是按词找，不套「剥净后不超过 10 个字不比对」那条。
- 匹配：中文说法（含夹带英文的，如「IC卡」）忽略空格按包含匹配；纯英文缩写（如 LCD、PSAM、eSIM）要求前后不是英文字母或数字；「不算的说法」先屏蔽再找。
- **各段输出什么、能不能发回**：
  - T1 只输出种子单号（输入里已有）、说法名称与是否，可以发回。
  - T2 只输出工厂名称（主数据），可以发回。
  - **T3 输出问题编号、订单号、CAR 编号、投诉单号与员工姓名**，不输出叙述文字。这些号要写进测试案例集（仓库里跟踪的文件），**发回前请业务方确认可以进仓库**，员工姓名尤其要确认；不同意的项只回告「有 / 没有这样的单」，由测试人在执行当天自己挑。
- 结果放到 `docs/1_user_input/probe_answers/`，按段号命名（如 `T1探测.md`），也可以直接贴在对话里。

## T2 三域工厂名称（可发回）

CN-011「今年上半年国内惠州的三个工厂」、XC-010「惠州工厂的问题」要知道哪些工厂名称里有「惠州」或与之相近。国内单的加工厂目前只有 04、05、09 三个工厂码（见国内主表字段说明）。

**T2a 国内工厂**。镜像里有国内工厂表时：

```sql
SELECT "FactoryID" AS "工厂码", "FactoryName" AS "工厂名称"
FROM "PaxFactory"
ORDER BY 1;
```

镜像里没有这张表时，在 ERP 实例（SQL Server）上执行：

```sql
-- SQL Server（ERP 实例）
SELECT FactoryID AS 工厂码, FactoryName AS 工厂名称
FROM paxbase.dbo.PaxFactory
ORDER BY FactoryID;
```

**T2b 巴西、海外工厂**（镜像库）：

```sql
SELECT '巴西' AS "域", f."FactoryName"::text AS "工厂名称", NULL::bigint AS "未删除单数"
FROM "Brazil_Factory" f
UNION ALL
SELECT '海外', o."Factory"::text, count(*)
FROM "OverseasProblemDetail" o
WHERE COALESCE(o."IsDelete"::int, 0) = 0
GROUP BY o."Factory"
ORDER BY 1, 2;
```

**结果怎么用**：本仓据此判断「惠州」按名称包含或相近能对上几家。对上的家数不是 3，或业务上「惠州的三个工厂」另有所指时，请业务方说明（open-questions D39）。

## T3 挑单（替换占位符；发回前请业务方确认可以进仓库）

每段挑几张，业务方从中选一张填进对应案例。只输出编号、姓名与计数，不输出叙述文字。

**T3a 当前责任人（CN-036）**：手上有未结案国内单、且没有同名同事的员工。

```sql
WITH h AS (
    SELECT DISTINCT m."ID" AS pid, btrim(x)::int AS uid
    FROM "ZCTracking_ProblemList" m
    CROSS JOIN LATERAL regexp_split_to_table(COALESCE(m."MemberList"::text, ''), ',') AS x
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
      AND m."Status"::int NOT IN (32, 13)
      AND btrim(x) ~ '^[0-9]+$'
)
SELECT e."Name" AS "姓名", count(*) AS "手上未结案单数"
FROM h
JOIN "Employee" e ON e."ID" = h.uid
WHERE (SELECT count(*) FROM "Employee" e2 WHERE e2."Name" = e."Name") = 1
GROUP BY e."ID", e."Name"
HAVING count(*) >= 2
ORDER BY 2 DESC
LIMIT 5;
```

**T3b 重名（XC-011）**：做过国内问题跟进人、又与别人同名的姓名。

```sql
WITH f AS (
    SELECT DISTINCT btrim(m."RUser"::text)::int AS uid
    FROM "ZCTracking_ProblemList" m
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
      AND btrim(COALESCE(m."RUser"::text, '')) ~ '^[0-9]+$'
)
SELECT e."Name" AS "姓名", count(*) AS "同名员工数",
    count(*) FILTER (WHERE e."ID" IN (SELECT uid FROM f)) AS "其中做过国内问题跟进人的人数"
FROM "Employee" e
WHERE e."Name" IN (SELECT e1."Name" FROM "Employee" e1 JOIN f ON f.uid = e1."ID")
GROUP BY e."Name"
HAVING count(*) >= 2
ORDER BY 3 DESC, 2 DESC
LIMIT 5;
```

**T3c 关联 CAR 的物料问题单（CN-042、XC-030、XC-032）**：XC-030 另需该单有生产订单。

```sql
SELECT m."Numbers" AS "问题编号", btrim(m."CAR"::text) AS "CAR编号",
    (SELECT count(*) FROM "ZCTracking_ProblemOrders" o WHERE o."ProblemId" = m."ID") AS "生产订单条数",
    EXISTS (SELECT 1 FROM "tbIQCreportOut" r WHERE r."fid"::text = m."CARID"::text) AS "报告表里查得到"
FROM "ZCTracking_ProblemList" m
WHERE COALESCE(m."IsDelete"::int, 0) <> 1
  AND m."ProblemType"::int = 3
  AND m."CARID" IS NOT NULL
  AND btrim(COALESCE(m."CAR"::text, '')) <> ''
ORDER BY m."AddDate" DESC
LIMIT 5;
```

**T3d 料号与 PN 两处都出现的 15 位编码（CN-043）**：没有结果时，分别给一个只在料号、只在 PN 出现的编码也可以。

```sql
WITH a AS (
    SELECT btrim(m."CInvCode"::text) AS code, count(DISTINCT m."ID") AS n1
    FROM "ZCTracking_ProblemList" m
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
      AND btrim(COALESCE(m."CInvCode"::text, '')) ~ '^[0-9]{15}$'
    GROUP BY 1
),
b AS (
    SELECT btrim(o."PartNumber"::text) AS code, count(DISTINCT o."ProblemId") AS n2
    FROM "ZCTracking_ProblemOrders" o
    JOIN "ZCTracking_ProblemList" m ON m."ID" = o."ProblemId"
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    GROUP BY 1
)
SELECT a.code AS "15位编码", a.n1 AS "料号位置命中单数", b.n2 AS "PN位置命中单数"
FROM a
JOIN b ON b.code = a.code
ORDER BY a.n1 + b.n2 DESC
LIMIT 5;
```

**T3d2 只在一处出现的 15 位编码（CN-043，T3d 后补）**：T3d 没有结果，说明目前没有编码同时出现在两处。各挑几个只在主表料号、只在生产订单 PN 上出现的编码，业务方从中选一个。

```sql

    SELECT '料号' AS pos, btrim(m."CInvCode"::text) AS code, count(DISTINCT m."ID") AS n
    FROM "ZCTracking_ProblemList" m
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
      AND btrim(COALESCE(m."CInvCode"::text, '')) ~ '^[0-9]{15}$'

    FROM "ZCTracking_ProblemOrders" o

    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
```

**T3p 打印话题的负样本（CN-057）**：比对文字里出现「打印机盖」「纸仓盖」「打印标签」「标签打印」，屏蔽这几个说法后再也没有打印话题的说法的国内单。

```sql
WITH src AS (
    SELECT m."ID" AS pid, c.x
    FROM "ZCTracking_ProblemList" m
    CROSS JOIN LATERAL (VALUES
        (m."ProblemDesc"::text), (m."Reason"::text),
        (m."Improve"::text), (m."Measures"::text), (m."Prevention"::text)
    ) AS c(x)
    WHERE COALESCE(m."IsDelete"::int, 0) <> 1
    UNION ALL
    SELECT r."ProblemId", string_agg(DISTINCT pp."PhenomenonDesc"::text, '；')
    FROM "ZCTracking_CheckReason" r
    JOIN "AfterSaleIssueClassPhenomenon" pp ON pp."ID" = r."PhenomenonID"
    GROUP BY r."ProblemId"
    UNION ALL
    SELECT s."ProblemId", c.x
    FROM (SELECT x.*, row_number() OVER (PARTITION BY x."ProblemId", x."Step"::int ORDER BY x."ID" DESC) AS rn
          FROM "ZCTracking_ProblemSteplog" x
          WHERE x."Step"::int IN (3, 4, 6, 10, 11, 13, 14, 35)) s
    CROSS JOIN LATERAL (VALUES
        (s."Opinon"::text), (s."Measures"::text),
        (CASE WHEN s."Step"::int = 6 THEN s."Result"::text END)
    ) AS c(x)
    WHERE s.rn = 1
),
doc AS (
    SELECT pid,
        replace(lower(string_agg(btrim(regexp_replace(regexp_replace(regexp_replace(regexp_replace(
            COALESCE(x, ''),
            'base64,[^"'']*', '', 'gi'),
            '<[^>]*>', ' ', 'g'),
            '&(nbsp|amp|lt|gt|quot|apos|#[0-9]+|#x[0-9a-f]+);', ' ', 'gi'),
            '[\s\u00a0\u3000]+', ' ', 'g')), ' ')), ' ', '') AS t
    FROM src
    GROUP BY pid
),
k AS (
    SELECT pid,
        t ~ '打印机盖|纸仓盖|打印标签|标签打印' AS has_ex,
        regexp_replace(t, '打印机盖|纸仓盖|打印标签|标签打印', '', 'g') AS mt
    FROM doc
)
SELECT m."Numbers" AS "问题编号", m."AddDate"::date AS "建单日期"
FROM k
JOIN "ZCTracking_ProblemList" m ON m."ID" = k.pid
WHERE COALESCE(m."IsDelete"::int, 0) <> 1
  AND k.has_ex
  AND NOT (k.mt ~ '打印|热敏头|走纸|卡纸|胶辊|纸仓|缺纸')
ORDER BY m."AddDate" DESC
LIMIT 5;
```
