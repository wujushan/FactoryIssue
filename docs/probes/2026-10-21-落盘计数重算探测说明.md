- **请一次跑完全部各段**（同一天、镜像同一次同步之后），这样所有数字是同一个时点的。R0 记下这个时点。
- 各段相互独立。某段报「表不存在」（镜像库没同步这张表）时，把报错原样存成同名文本，其余照常执行；R1 会先列出哪些表不在镜像库里。
- 待办任务表约 420 万行、文档清单约 193 万行，R1、R5c、R5d 会慢一些，属正常。
- 只看未删除的单（国内是否删除不为 1；巴西状态不为 -1；海外是否删除为 0），R1、R2 例外（含已删除的单）。

```sql
SELECT w."序号", w."库", w."表",
       COALESCE(t.table_schema, '（镜像库里没有）') AS "镜像库 schema",
       CASE WHEN t.table_name IS NOT NULL THEN
           (xpath('/row/n/text()',
                  query_to_xml(format('SELECT count(*) AS n FROM %I.%I', t.table_schema, t.table_name),
                               false, true, '')))[1]::text::bigint

FROM want w
```

**R3a 整机与物料单、子表比例**

```sql
WITH m AS (
    SELECT "ID",
           CASE WHEN NULLIF(btrim("MHead"::text), '') IS NULL THEN '整机（物料标识为空）'
                ELSE btrim("MHead"::text) END AS kind
    FROM "ZCTracking_ProblemList"
    WHERE COALESCE("IsDelete"::int, 0) <> 1
),
s AS (SELECT "ProblemId" AS pid, count(*) AS n FROM "ZCTracking_ProblemSteplog" GROUP BY 1),
o AS (SELECT "ProblemId" AS pid, count(*) AS n FROM "ZCTracking_ProblemOrders"  GROUP BY 1),
x AS (SELECT "ProblemId" AS pid, count(*) AS n FROM "ZCTracking_XBOrders"       GROUP BY 1),
t AS (SELECT "ProblemId" AS pid, count(*) AS n FROM "ZCTracking_OtherOrder"     GROUP BY 1),
p AS (SELECT "ProblemId" AS pid, count(*) AS n FROM "ZCTracking_ProductNames"   GROUP BY 1)
SELECT m.kind AS "物料标识",
       count(*)                AS "单数",
       COALESCE(sum(s.n), 0)   AS "处理步骤条数",
       COALESCE(sum(o.n), 0)   AS "生产订单条数",
       count(o.pid)            AS "有生产订单的单数",
       COALESCE(sum(x.n), 0)   AS "小板订单条数",
       count(x.pid)            AS "有小板订单的单数",
       COALESCE(sum(t.n), 0)   AS "其他在线订单条数",
       count(t.pid)            AS "有其他在线订单的单数",
       COALESCE(sum(p.n), 0)   AS "机型条数",
       count(*) FILTER (WHERE o.pid IS NULL AND x.pid IS NULL) AS "生产订单、小板订单都没有的单数"
FROM m
LEFT JOIN s ON s.pid = m."ID"
LEFT JOIN o ON o.pid = m."ID"
LEFT JOIN x ON x.pid = m."ID"

LEFT JOIN p ON p.pid = m."ID"

ORDER BY 2 DESC;
```

**R4f 只有 1 位数字的 PN 编码**（2026-10-22 补充，用于 B17）

R4d 显示 52 条申请单的 PN 编码只有 1 位数字。R4f1 看这个数字是几、涉及的单上有没有别的 15 位 PN，只输出计数，可以发回：

```sql
WITH po AS (
    SELECT po."ProblemID" AS pid, btrim(rl."PartNumber"::text) AS pn
    FROM "BrazilProblemPO" po
    JOIN "BrazilProblemList" b ON b."ID" = po."ProblemID" AND b."Status"::int <> -1
    JOIN "Brazil_RequestList" rl ON rl."ID" = po."RequestID"
)
SELECT a.pn                    AS "1 位数字的 PN 编码",
       count(*)                AS "关联申请单条数",
       count(DISTINCT a.pid)   AS "涉及单数",
       count(DISTINCT a.pid) FILTER (
           WHERE NOT EXISTS (SELECT 1 FROM po b2 WHERE b2.pid = a.pid AND b2.pn ~ '^[0-9]{15}$')
       )                       AS "其中没有 15 位 PN 的单数"
FROM po a
WHERE a.pn ~ '^[0-9]$'
GROUP BY 1
ORDER BY 2 DESC;
```

R4f2 按两种情况分类列出全部这样的单，供到管理页面逐类核对：

- **1 只有 0**：单上的申请单 PN 编码只有 0，没有 15 位 PN（R4f1：14 张）；
- **2 有 0，另有 15 位 PN**：单上既有 PN 编码为 0 的申请单，也有 15 位 PN 的（R4f1：29 张）。

> **本段输出问题编号，结果只在内网对照管理页面用，不要发回，也不要放进 `docs/1_user_input/`。** 只需按分类回告页面上 PN 一栏显示什么。

```sql
WITH po AS (
    SELECT po."ProblemID" AS pid, btrim(rl."PartNumber"::text) AS pn
    FROM "BrazilProblemPO" po
    JOIN "Brazil_RequestList" rl ON rl."ID" = po."RequestID"
),
agg AS (
    SELECT pid,
           count(*) FILTER (WHERE pn ~ '^[0-9]$')      AS n_one,
           count(*) FILTER (WHERE pn ~ '^[0-9]{15}$')  AS n_pn,
           count(DISTINCT pn) FILTER (WHERE pn ~ '^[0-9]{15}$') AS n_pn_distinct
    FROM po
    GROUP BY pid
)
SELECT CASE WHEN a.n_pn = 0 THEN '1 只有 0' ELSE '2 有 0，另有 15 位 PN' END AS "分类",
       b."OrderNumber"                                      AS "问题编号",
       b."AddDate"::date                                    AS "建单时间",
       CASE b."Status"::int
            WHEN 0 THEN '待提交' WHEN 10 THEN '待修改类别' WHEN 20 THEN '待跟进'
            WHEN 25 THEN '待设计更改' WHEN 26 THEN '待SQE确认' WHEN 30 THEN '待效果确认'
            WHEN 40 THEN '待结案' WHEN 50 THEN '已结案' WHEN -2 THEN '已终止'
            ELSE '其他取值' END                             AS "状态",
       a.n_one                                              AS "PN 编码为 0 的申请单条数",
       a.n_pn                                               AS "15 位 PN 的申请单条数",
       a.n_pn_distinct                                      AS "不同的 15 位 PN 个数"
FROM agg a
JOIN "BrazilProblemList" b ON b."ID" = a.pid AND b."Status"::int <> -1
WHERE a.n_one > 0
ORDER BY 1, 3 DESC, 2;
```

结果应为 43 行：分类 1 共 14 行、分类 2 共 29 行，与 R4f1 一致。

**核对时看什么**：每类挑一两张，在管理页面打开，回告：

**结果怎么用**：R4a 替换待提交、已终止等张数（统计口径的示例顺带改）。R4b 替换未删除张数、填了大机型的张数、处理过程条数与「有单尚无处理过程」的张数、每单平均费用明细条数；「含全角逗号」不为 0 时，大机型的拆分规则补上全角逗号。R4c 替换「有值的单共多少段、全部能对上」。R4d 替换关联申请单条数、每单平均条数、对不上 PN 主数据的条数与编码位数区间。R4e 替换「是否涉及费用」标记与明细对不上的几组数，以及「涉及费用的单」张数（标记无关，按明细美元或雷亚尔大于 0 合计）与只有雷亚尔的张数。

## R6 文本存日期的写法

```sql
SELECT c."域", c."列",
       CASE WHEN NULLIF(btrim(c.v), '') IS NULL THEN '1 空'
            WHEN btrim(c.v) ~ '^[0-9]{4}-[0-9]{2}-[0-9]{2}$' THEN '2 YYYY-MM-DD'
            ELSE '3 其他写法' END AS "写法",
       count(*) AS "行数"
FROM (
    SELECT '巴西' AS "域", '主表停线日期' AS "列", b."StopDate"::text AS v
    FROM "BrazilProblemList" b WHERE b."Status"::int <> -1
    UNION ALL
    SELECT '巴西', '主表现场发现日期', b."ProblemDiscoveryDate"::text
    FROM "BrazilProblemList" b WHERE b."Status"::int <> -1
    UNION ALL
    SELECT '巴西', '主表统计日期', b."StatisticsDate"::text
    FROM "BrazilProblemList" b WHERE b."Status"::int <> -1
    UNION ALL
    SELECT '巴西', '处理过程计划完成日期', p."PlanCompleteDate"::text
    FROM "BrazilProblemProcess" p
    JOIN "BrazilProblemList" b ON b."ID" = p."ProblemID" AND b."Status"::int <> -1
    UNION ALL
    SELECT '巴西', '处理过程设计更改评估时间', p."DesignEstimateDate"::text
    FROM "BrazilProblemProcess" p
    JOIN "BrazilProblemList" b ON b."ID" = p."ProblemID" AND b."Status"::int <> -1
    UNION ALL
    SELECT '海外', '主表现场发现日期', o."FoundDate"::text
    FROM "OverseasProblemDetail" o WHERE COALESCE(o."IsDelete"::int, 0) = 0
    UNION ALL
    SELECT '海外', '主表停线日期', o."StopDate"::text
    FROM "OverseasProblemDetail" o WHERE COALESCE(o."IsDelete"::int, 0) = 0
    UNION ALL

    FROM "OverseasProblem_DeliveryOrder" d
    JOIN "OverseasProblemDetail" o ON o."Id" = d."ProblemId" AND COALESCE(o."IsDelete"::int, 0) = 0
) c
GROUP BY 1, 2, 3
ORDER BY 1, 2, 3;
```
