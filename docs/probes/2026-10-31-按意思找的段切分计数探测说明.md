## Y1 被切开的栏目有多少（测试环境产物库，可发回）

按意思找的段表里，一个栏目只有序号 0 的一段就是没切；有序号 1 及以上的段就是被切开了。`整单一段` 一列应为 0（现用的不是 `whole`）。

```sql
SELECT '国内' AS "域", count(DISTINCT issue_id) AS "单数", count(*) AS "段数",
       count(DISTINCT (issue_id, field)) AS "栏目数",
       count(DISTINCT (issue_id, field)) FILTER (WHERE seq > 0) AS "被切开的栏目",
       count(*) FILTER (WHERE seq > 0) AS "切出来的后续段",
       count(*) FILTER (WHERE field = 'whole') AS "整单一段"
FROM public.domestic_issue_vseg
UNION ALL
SELECT '巴西', count(DISTINCT issue_id), count(*), count(DISTINCT (issue_id, field)),
       count(DISTINCT (issue_id, field)) FILTER (WHERE seq > 0), count(*) FILTER (WHERE seq > 0),
       count(*) FILTER (WHERE field = 'whole')
FROM public.brazil_issue_vseg
UNION ALL
SELECT '海外', count(DISTINCT issue_id), count(*), count(DISTINCT (issue_id, field)),
       count(DISTINCT (issue_id, field)) FILTER (WHERE seq > 0), count(*) FILTER (WHERE seq > 0),
       count(*) FILTER (WHERE field = 'whole')
FROM public.overseas_issue_vseg;
```
