# 2026-11-04 「未填」不参加排名

## 背景

手动测试 XC-022「上个月问题最多的机型是哪个？把它的单列出来，不良率最高那张的原因是什么？」。上个月只有 1 张巴西单，没填大机型。回答是「问题最多的机型是『未填』」；第二步按「未填」去对机型，答「没有找到机型『未填』，请核对名称」；第三步没有执行。

排查出四处：

1. 统计把没填的单归进「未填」一组，排名时与真实取值一视同仁，「第一」成了「未填」，写结论的模型又必须点到第一名。
2. 步骤间引用（`top1`、`top_values`）直接收了「未填」，后一步拿它对库。
3. 引用的前一步给不出取值时（只有「未填」一组、单都没填加工厂、前一步出错），各域对库把空的条件跳过，后一步就不带这个条件查了全部。比报错更糟：答案看起来没问题，答的却不是用户问的那个机型。现有口径「某一步没有结果时写明，停在这一步」只管 0 张，没管「有单、没有可承接的取值」。
4. 三域一起取前 N 名、名字分属不同的域时，各域对库遇到第一个本域没有的名字就整域转成追问，三域都这样时整步失败（规划提示自带的例子「问题最多的三个工厂各有哪些单」就会撞上）。

另有一处与提示不一致：规划提示说 `top_values`「没写 top 时同 top1」，代码在只说「最多的」时取了前 10 名。

## 结论

开发者 2026-11-04 同意 G87–G90 的建议。2_landed 已按此改写（总述「跨域归并」「问题等级」「通用筛选规则」「一问多段」「排名、长清单与导出」）。

- **G87**：「未填」照常列一行、排在表格最后，不占名次；不参加第一、前 N 名、并列与「哪些增加了」，后一步不接它。结论另写「另有 N 张没填机型」，按机型、系列统计时注明其中物料单几张（国内物料单本来不挂机型）。没填的比第一名还多时加一句。只有「未填」一组时不点名第一，后一步停下。「未识别机型」同样处理。张数都由沙箱算。
- **G88**：海外问题类型「其他（未识别）」按 G87 处理。
- **G89**：除问题等级外不按「没填」筛；用户要找没填某一项的单时说明目前不能筛，不请用户核对名称。
- **G90**：取值来自前一步时，各域只用本域对得上的，开头写明对不上的，一个都对不上的域不计入；用户自己说的名称照旧追问。

不需要新口径、当天先修的两处：

- 引用的前一步没给出取值时，后一步不取数，写「前一步没有得出可以承接的 X」并停下（设计 §8「链式步骤」原本就这样写，代码没做到）。
- `top_values` 没写名次数时同 `top1`。

措辞上改了一处：G87 建议里的「多数单没填机型，排名只反映已填的单」，没填的比第一名多不等于过半，改写成「没填机型的单比排第一的还多，排名只反映已填机型的单」。
