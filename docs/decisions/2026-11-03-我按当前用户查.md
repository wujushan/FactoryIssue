# 2026-11-03 「我」按当前用户查

## 背景

业务方通用测试案例集「权限与隐私 · 当前用户身份」里有「我负责的」「我手上的」「我跟进的」这类问法。2026-10-28 开发者定暂缓（open-questions G70）：`2_landed` 没写「我」怎么认，前提是核对平台注入的工号与人员表员工 ID 的关系，原计划写一条探测。在那之前，这类问法按问句里没有人员处理。

## 结论

开发者 2026-11-03 定：可以开工；**平台给出的工号就是人员表的员工 ID**，不用写探测。

- 「我」「本人」「自己」指提问的人。按工号（`UserContext.user_id`）对到人员表的员工，不按姓名对，所以不会重名，也不看平台注入的姓名。
- 对到之后照总述「三域共用的说法」已有的几行查：「我跟进的」「我的单」按问题跟进人；「我手上的」「待我处理的」按当前责任人，巴西不计入；「我负责的」按责任人。回答开头写明「「我」按当前用户 X 理解」。
- 工号为空、不是数字、人员表里没有这名员工时，说明认不出是哪位员工、请用户给出姓名，本轮不出数，不按全部单查。人员表取数出错时，该段按「这一部分暂时没查到」答。
- 「帮我查」「给我列」里的「我」只是语气，不是条件。

「我的单」按问题跟进人，是照「只说人名」那一行推出来的，开发者没有单独定。
