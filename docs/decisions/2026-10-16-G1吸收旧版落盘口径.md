# 2026-10-16 G1 吸收旧版落盘口径

## 背景

本模块合并了此前分域建设的国内、巴西、海外三个制程问题查询助手。开发者提供了三域旧版落盘文档（业务方此前已确认的口径）供本次 G1 梳理对照。本记录说明哪些内容被吸收进 `docs/2_landed/`、哪些与新材料冲突转入歧义清单、哪些未采纳。

## 采纳为已定口径

旧版文档中业务方已确认的业务结论直接落盘，对应歧义项关闭：

| 域 | 内容 | 关闭的歧义项 |
|---|---|---|
| 国内 | 曾经停线 = 是否停线为 1，重启不清零 | D1 |
| 国内 | 加工厂单值工厂码 | D2 |
| 国内 | 问题跟进人单值，且只有硬件、软件、结构问题、制程优化指定；物料、工厂制程、资料问题不指定 | D3 |
| 国内 | 机型直接用机型子表名称与系列 | D4 |
| 国内 | 本域 13 张表，无库存表 | D5 |
| 国内 | 处理步骤：完整过程全保留，某环节最新取 ID 最大 | D6 |
| 巴西 | 问题类型 `其他\|备注` 格式 | B2 |
| 巴西 | 问题现象 JSON 键与展平规则 | B3 |
| 巴西 | 不良率 = 不良数量 × 100 ÷ 影响数量 | B4 |
| 巴西 | 大机型逗号分隔、去空格 | B5 |
| 巴西 | 不接 ERP 物料分类表 | B8 |
| 海外 | 已选问题现象展平规则 | O3 |
| 海外 | 物料与供应商名称取 JSON，不关联存货档案与供应商表 | O4 |
| 海外 | 加工厂直接存名称 | O5 |

另有大量补充直接并入字段说明与各域业务描述，未单列歧义项：国内不良率与影响数量的定义、停线中四状态、小板订单工厂存名称、责任人处理结果派生、原因分类、产品在制属性、富文本格式、发现工位写法；巴西一行一单收敛规则、费用汇总与专项费用明细、费用类型枚举、加工厂按段匹配、PN 列表、停线组合态、结案结果语义、SQE 两步、投诉单号写法、主表规模；海外物料逐条展示、发货单展示顺序与合计、PN 名称、系列不作条件、附件有效性、当前处理人不用步骤成员代替；链接规则的加密细节（CBC、PKCS7、大写十六进制、不做 URL 编码、只用 `check`）与「测试、正式都配正式站点」。

## 与新材料冲突，转入歧义清单

| 冲突 | 歧义项 |
|---|---|
| 巴西停线状态：旧口径只有「空 / 停线重启」，源系统查询里出现「停线中」 | B1 |
| 巴西当前处理人：新业务描述稿要求三域都能问当前处理人，旧口径未定义、未纳入流程待办任务表 | B6 |
| 巴西涉及存货子表：新材料新增，旧口径未纳入 | B7 |
| 海外附件：旧口径只按业务记录 ID + 删除标志，没有业务名称条件 | G8 |
| 链接站点：旧口径巴西制程单与附件预览分两套站点，新材料统一写 INFO 站点 | G11 |
| 跨域汇总呈现：旧口径明确「本阶段不决议」 | G12 |

新增歧义：D7（国内「某部门处理的」与不指定跟进部门的三类问题）、B11（巴西是否类字段数字写法对应）。

## 未采纳

旧版文档中的技术方案内容不进入 G1：分域独立数据集市、源数据镜像 / 主查询视图分层、向量化范围与重建命令、字段「只投影不筛选」等实现约束、旧系统配置项名。这些属于 G2 / G4 决策，按本平台「原始取数直连 info、仅治理或向量化才建 mart」的路线重新评估。

旧版文档中的真实数据行（如某张巴西单的费用明细实测值、富文本示例原文）不复制进 `2_landed`，只保留规则。
