# 2026-11-05 点名的数据项先对上再答

## 背景

开发者 2026-11-05 手动测试「ZC2609012 的责任归属部门」「ZC2609012 的供应商」「BR2604003 的责任归属部门」，三句都答「本助手没有『X』这一项」。这三项本助手都有，`2_landed` 也写了各自怎么答。开发者另指出这句话本身分不清是「没查到」还是「不支持」。

用 S4 假数据复现（ZC9901001 在途、ZC9901002 物料问题且有供应商、BR9901001 有供应商），三句都错，原因有三处：

- 单张单详情的「其他:X」只拿这张单详情里**已显示**的栏目名去对，判断方向是「栏目名包含在用户的话里」。「供应商名称」不在「供应商」里，有值也对不上。
- 国内详情只在已定责、且不是物料问题时才显示责任归属部门；没定责、物料问题的单栏目不在，就落到「没有这一项」。
- 巴西、海外问责任归属部门应按问题跟进部门给并写明（术语表「责任归属部门」），代码直接说没有。

另外「供应商」不是任何显示名或别称，列清单「带上供应商」同样会误报。

## 结论

开发者 2026-11-05 定：

- 点名的数据项先按显示名与术语表对。对上了按这一项自己的规则答：这张单为空照该项写法（「未填」「无需定责」「未定责」、物料问题不展示责任归属部门）；本域没有就说明本域的单上没有，有替代口径的按替代口径给（巴西、海外的责任归属部门给问题跟进部门）。
- 三个域都对不上时的说法由「本助手没有『X』这一项」改为「**制程问题单上没有『X』这项信息**」。
- 只说「供应商」指供应商名称，问单张单时连供应商编号一起给。写进总述「三域共用的说法」，代码照「处理人」的做法接上；不加进术语表，规划提示不变（仍是 p2.4），不用重跑对照集。
