# 2026-11-06 按多值维度既筛又分组

## 背景

开发者 2026-11-06 手动测试「Q92和IM30今年哪个问题最多？」。统计口径的筛选条件写「机型：Q92、IM30」，结论只说 Q92 21 张、IM30 14 张，表格和图却多出一行 Q60（1 张）。三处对不上。

查实的原因：

- 按机型筛是「单上的机型与筛选的机型有交集即计入」（沙箱 `vw_cond_mask` 的 any_of）。一张单登记了 Q92、Q60，因 Q92 计入，Q92 的 21 张里有它。
- 分组时一单在它的每个取值下各计一次（总述「统计口径说明」多值归属），这张单又在 Q60 下计了一次。分组不知道本步按机型筛过，没有把分组限定在筛选的取值上（`vw_group`）。
- 表、图、结论用的是沙箱给的同一段数据，Q60 也在结论的事实里。结论没提 Q60，是写结论的模型照着【本次查的是】（机型：Q92、IM30）自己略过的，程序没拦。
- 落盘只写了多值归属「一单在每组各计一次」，没写同时按同一维度筛时怎么办。

这是共性问题。一单可多值、又能按它筛的维度都有同样的形状：机型、系列，巴西加工厂，国内当前责任人、责任归属部门，海外问题跟进人、当前责任人，按处理环节筛的状态。

## 结论

按开发者报告的期望处理（G98）：

1. 按一单可多值的维度筛、又按同一维度分组时，分组只列筛选的取值。单上同时登记的其他取值不另列。
2. 统计口径加一句：「按机型分组只列筛选的机型（Q92、IM30），单上同时登记的其他机型不另列」。
3. 否定的条件（「不是 Q92」）不限定分组。留下的单本来就没有那些取值。
4. 不按这一维度筛时照旧，一单在它的每个取值下各计一次。
5. 一单在这一维度的取值一个都对不上筛选的取值时，这张单照原样计，不掉出分组。按机型、系列、工厂、环节筛时不会出现。按人员 ID 筛、按姓名分组时，单上的姓名写法可能与人员主数据不同。

## 补记：按与它成对的另一维度筛（G99，开发者 2026-11-06 同意建议）

### 背景

排查 G98 时发现：筛选和分组是两个维度、两者在单上又有对应关系时，同样会列出筛选范围外的取值。有两组：

- **机型与系列**（国内、巴西；海外没有系列）：一个机型只属于一个系列。问「A 系列哪个机型问题最多」，一张单登记了 A920（A 系列）和 Q92（Q 系列），它因 A920 计入，按机型分组时 Q92 也单独占一行。反过来按机型筛、按系列分组，会多出 Q 系列一行。
- **国内的处理环节与当前责任人**：当前状态每一行是「环节 + 人」。问「张三手上的单都卡在哪个环节」，一单当前状态为「SQE跟进 张三 / IQC确认 李四」，按环节分组时 IQC确认 下也计一次，可这个环节不是张三在处理，结论会写错。反过来按 SQE跟进 筛、按当前责任人分组，会多出李四。海外一单只有一个环节，巴西没有当前责任人，都不受影响。

### 结论

1. 两组都限定，分组只留与筛选取值对应的部分：
   - 按系列筛、按机型分组：只列该系列的机型；
   - 按机型筛、按系列分组：只列这些机型所属的系列；
   - 国内按当前责任人筛、按处理环节分组：只计这个人所在那几行的环节；
   - 国内按处理环节筛、按当前责任人分组：只计这个环节那一行上的人。那一行上没有人时，这张单计入「没有当前责任人」。
2. 统计口径写一句，如「按机型分组只列与筛选的系列（A系列）对应的机型，单上同时登记的其他机型不另列」。
3. 只限定单上有明确对应关系的组合。看不出对应关系的组合照旧每个取值各计一次，例如巴西一单的工厂「CA、TT」与机型「A920、Q92」。
4. 几项条件都与同一分组有关时取交集（按张三筛、又按 SQE跟进 筛，按环节分组只计 SQE跟进 且张三在的那一行）。
5. 计入哪些单、总单数都不变，只变各组张数。单上的取值都在筛选范围内时（多数单）结果不变。
