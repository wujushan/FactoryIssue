# 2026-10-20 国内并行阶段追加进行中的退货 / 退库

修订决策 2026-10-19「国内当前状态并行阶段取待办任务」中的 D14 结论。

## 原口径

D14：状态 30、36、37（效果确认与预防对策确认并行）的当前状态只取待办任务，不追加 IQC 段与退货 / 退库段。

## 依据

- 探测 C2（业务方 2026-10-20 内网计数）：并行阶段的单 IQC 状态全为空；有 1 张状态 37 的单有进行中的退货 / 退库记录（open-questions D21）。
- 业务方 2026-10-20 在源系统管理页面核对这张单，当前状态显示两行：「预防对策确认」+ 待办任务人员，「填写退库信息」+ 风险订单责任人。源系统在并行阶段会追加进行中的退货 / 退库行。

## 结论

- 并行阶段的当前状态 = 待办任务行（先效果确认、后预防对策确认）+ 进行中的退货 / 退库行，退货 / 退库行规则同「其他状态」第三段，排在最后。查不到已接受任务时用状态文案 + 主状态处理人兜底，退货 / 退库行照常追加。
- 当前责任人随之加上进行中的风险订单责任人；按「填写退货信息 / 填写退库信息」筛选、按人查「手上的单」都能命中这类单。
- IQC 段仍不追加。并行阶段目前没有 IQC 状态有值的单，管理页面上无从核对；日后出现时按 D19 的做法核对页面再定。
