# 2026-11-06 问一批单谁在处理

## 背景

开发者 2026-11-06 手动测试「巴西的单里，谁现在在处理？」。规划器的理解是「巴西域当前正在处理问题单的人（当前责任人）」，计划是巴西清单、点名列「当前责任人」，没有状态条件。回答是：

- 开头一行「巴西不提供当前责任人。」；
- 结论句「巴西不提供当前责任人，无法查询谁在处理。」；
- 接着是巴西全部单的要点（问题类型、积压、严重程度、重复出现）与需关注。

开发者指出两点：同一句话说了两遍；结论句之后直接是要点，用户不知道助手查的是什么、是怎么理解的。

用单测的假数据复现，查实的原因：

- 开头那一行是程序写的提示行，结论句是模型写的。写结论的提示要求不重复提示行，但代码没有核对这一条，照抄了也放行。
- 清单遇到本域没有的列时不放这一列（设计 §9.2）。巴西没有当前责任人，表格只剩问题编号一列。模型看到的表只有单号，用户又问「谁在处理」，只能写「无法查询」，第一行既重复了提示行，也没说这次查了哪些单、几张。
- 总述「三域共用的说法」写的是巴西「说明后给出问题跟进人」，没有限定问单张单；巴西业务描述与术语表只写了问单张单。清单这种情形落盘不全，代码按「不放这一列」做了。
- 规划器没有加状态条件，已结案的单也列了出来；已结案的单没有人在处理。

## 结论

开发者 2026-11-06 同意建议：

1. **结论句不照抄提示行**：结论句里照抄了提示行的某个分句（去掉空白、引号与标点后不短于 6 个字）时，打回重写一次，告诉模型这句已经显示在上面，第一行改为直接回答这次查了几张、未结案几张等；仍照抄就用模板句。只认原样照抄：漏认只是多一句重复，认错只是多重写一次，最后有模板句兜底，两头都不会写错。
2. **巴西清单点名当前责任人时给问题跟进人**：巴西表格的这一列给问题跟进人，回答开头写明「巴西不提供当前责任人，下面给出问题跟进人」。按当前责任人筛（「张三手上的单」）时巴西仍不计入，不改按问题跟进人列单（决策 2026-10-20「G1 全局 review 修订」B6 不变）。（G96）
3. **问一批单现在谁在处理、没点名某个人时，只列未结案的单**，默认列后面加当前责任人一列。用户明说要已结案的或全部的单、或只是让清单带上当前责任人一列时照用户说的。这是开放的问法，交规划器理解：规划提示加一句（p2.6），术语表「当前责任人」一行跟着改，对照集 c10 加 V-74–V-78，要在内网跑。不在代码里按计划结构补状态条件：「列出近 30 天的单，带上当前责任人」与这一问的计划结构相同，补了就错。（G97）

## 内网实测

开发者 2026-11-06 在内网跑 p2.6（Qwen3-Fast，「现状+校验」组，0 次调用出错）：

```powershell
uv run python scripts/planner_spike/spike.py --run --confirm-local --parts plan --groups 现状+校验 --only V-74,V-75,V-76,V-77,V-78 --out runtime/planner_spike/<日期>-p2.6-谁在处理
uv run python scripts/planner_spike/spike.py --run --confirm-local --parts plan --groups 现状+校验 --out runtime/planner_spike/<日期>-p2.6
```

- **新加的五句**（`20261106-p2.6-谁在处理`，25 次）：全对，多次一致 100%，首次就合格。V-74–V-77 每次都写了未结案与当前责任人一列；V-78「带上当前责任人」每次都只加列、不加状态条件。
- **全量**（`20261106-p2.6`，对照集 c10 共 266 条，1,330 次）：整份全对 98.3%（p2.4 的 1,245 次按现行代码与对照集重算为 97.7%，原汇总 98.1%），照线上先走号码直通 98.6% / 多次一致 97.0%（p2.4 为 98.5% / 97.6%），业务问句写成介绍 1 次。错例 23 次，都不是这句提示带出来的：
  - M-15、M-16 每次都错，M-08 线上走号码直通，三条 p2.3 起就这样；U-09 写成「只读请求」1 次（p2.4 为 5 次）。
  - CN-009 错 3 次（p2.4 为 1 次）、XC-021 错 3 次（第二步没写「在上面的结果里」，p2.4 为 0 次）、U-19 写成介绍 1 次：这三条在 p2.3 也各错 5、5、1 次，p2.4 正好没错，属于提示变长后在两种写法之间摆动，与「谁在处理」无关。CN-013（p2.4 错 3 次）这次全对。
- **有没有用过头**：逐条比 p2.4 与 p2.6 的计划，多写当前责任人一列或未结案条件的只有两句。V-06「张三手里压着几张单」5 次都加了未结案（期望里本就允许，已结案的单也没有当前责任人，结果相同）；P-20「上个月三个域一共多少？巴西那几张为什么没结？」第二步 3 次加了当前状态与当前责任人两列（巴西照新规则给问题跟进人并写明，不算错）。「某人手上的」CN-036、V-47 与 ME 组都没有变化、都对。
