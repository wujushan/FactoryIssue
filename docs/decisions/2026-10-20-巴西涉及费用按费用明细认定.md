# 2026-10-20 巴西「涉及费用的单」按费用明细认定

## 背景

示例问题「巴西今年涉及费用的单子共花了多少美元」有两种认定方式：主表「是否涉及费用」标记为「是」，或费用明细合计大于 0；扣款费用算不算「花了多少」也没定（open-questions B14）。

## 依据

探测 C9a（业务方 2026-10-20 内网计数，未删除 191 张单）：

| 是否涉及费用 | 费用明细 | 单数 |
|---|---|---|
| 是 | 美元合计大于 0 | 170 |
| 是 | 只有雷亚尔合计大于 0 | 1 |
| 是 | 合计都为 0 | 1 |
| 否 | 没有费用明细 | 17 |
| 否 | 美元合计大于 0 | 1 |
| 测试值 0 | 没有费用明细 | 1 |

两种判据都是 172 张，有 2 张单的归属不同。最新处理过程扣款大于 0 的 88 张单，都已有美元明细。

## 结论

业务方 2026-10-20 同意：

- 「涉及费用的单」= 费用美元合计或费用雷亚尔合计大于 0，不看标记。这样计入的单都有金额，有金额的单都计入。雷亚尔要算进判据，否则只有雷亚尔的那张单会漏掉。
- 「花了多少」只合计费用明细，美元、雷亚尔分别给出，不换算、不相加；问美元时另行说明只产生了雷亚尔费用的单。
- 扣款（转嫁给供应商的金额）不并入费用，需要时单列。
- 用户明说「是否涉及费用为是 / 否」时，仍按标记筛。
