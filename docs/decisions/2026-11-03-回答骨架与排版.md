# 2026-11-03 回答骨架与排版

## 背景

开发者 2026-11-03 测「之前有过摄像头镜片脏污的现象吗」，回答依次是：
- 三行几乎一样的开头（「国内按现象描述找到 10 张相近的问题，按相近程度排序，不保证完整」，巴西、海外各一行）和一行合计；
- 模型写的分析段；
- 三张表；
- 统计口径。

开发者指出两类问题：程序写的那部分本身的内容和排版不好；程序写的和模型写的拼在一起不协调。要一套统一的优化方案。

查实的原因：
- 同一件事说了好几遍。张数在开头逐域说一遍、合计再说一遍，分析段第一句又说一遍；「按相近程度排序，不保证完整」每域一遍，统计口径里还有一遍。分析段的提示要求第一句报张数，又不知道开头已经说过。分析段的提示还写着「只写表格下面的一段」，2026-11-02 起它已经放在表格上面。
- 写分析的模型只看到表名、列名和行数，看不到单的内容，答不了「有没有」。类似问题不按词分组，事实里「直接提到」恒为 0，模型据此说「没有一张直接提到该现象」，与它前一句「有过相关记录」矛盾。
- 类似问题每域固定取最相近的 10 张，相近程度门槛默认不启用，所以每次都说「找到 10 张」，读起来像查到了 10 张。
- 清单与统计的分析维度（问题类型分布、机型前几名）也注入到类似问题的分析里，「最相近的 10 张」按问题类型分布没有意义。
- 同一批单三种叫法：开头「相近的问题」、分析段「可能相关的单」、表格标题「按文字找到的单」。
- 段标题、表格标题、统计口径都是同一级粗体；块之间的空行散在十几处代码里各自加，偶尔连段或多空行。

## 结论（开发者 2026-11-03 定）

1. **回答骨架**：清单、统计、按文字找单、临时统计，每段按这个顺序：
   1. **提示行**（有才给）：按什么理解、沿用了上一轮的哪些条件、哪些域无权或未计入、「以下为临时统计」、本次按哪些说法找等。程序写，一段。
   2. **结论**：模型写，3 到 6 句的段落，不用标题和列表。模型没写出来、核数不过，或结果只有一两张不写分析时，用程序的模板句。
   3. **明细**：每域一节（统计是每张表一节）。小标题写这一节的张数；下面是表格与图；表格没列全、分组的含义写在表格下面一句。按文字找单「要增减说法时可以直接说……」「候选较多……可以加条件再查」放在各节之后。
   4. **结尾**：统计口径（只按文字找单的轮次叫「查找说明」）、导出链接、可点的选项，整轮一次。

   一问多段时每段前面是段标题；提示行只在第一段，结尾整轮一次。单张单详情、按编号查单不写结论，照旧。
2. **结论只有模型一个作者，程序的模板句只作退路**：
   - 原先程序写的开头一句不再和分析段并列，改作模型没写出来时的模板句。
   - 各域张数写在小标题上，结论不逐域报张数，需要时说合计或点名最多的域。
   - 问「哪个最多」时第一句点名第一，并列的全部点名。程序核对点全了没有：没点全重写一次，仍不行用模板句。
   - 写结论的模型能看到提示行，不重复它，但结论要与它一致。
3. **每样信息只放一处**：

   | 信息 | 放在哪 |
   |---|---|
   | 用户问题的直接答案（有没有、多少、哪个最多、增没增） | 结论第一句 |
   | 重点单号与点名理由 | 结论 |
   | 各域张数 | 该域小标题（「国内问题单（31 张）」） |
   | 三域合计 | 结论；统计表的小标题写合计 |
   | 时间范围 | 结论第一句与结尾；表格小标题不再带时间 |
   | 找法与是否完整（按相近程度排序、最多几张、不保证找全） | 结尾 |
   | 本次按哪些说法找 | 提示行（结尾不再重复） |
   | 无权、未计入的域 | 提示行与结尾「统计范围」 |
   | 表格只列了前几张 | 该域表格下面 |
   | 分组的含义（处理中提到的多是顺带提到） | 该域表格下面 |
   | 时效（半小时内新建的单可能没纳入） | 结尾 |

4. **类似问题**：
   - 每域默认列 5 张，管理员可改（`answer_params.toml` 的 `similar_rows`）。逐张判断的张数不跟着改（决策 2026-11-03「类似问题逐张判断与分数下限」）。小标题写「最相近的问题（N 张）」，不说「找到 N 张」。
   - 列出的单已经逐张判断过是同一类现象（同上决策）。写结论的模型拿到每域列出的单的内容：问题编号、问题描述摘要、命中处、原因与措施、是否已结案。它点名最像的两三张和当时怎么处理的、结案没有；不按问题类型、机型分布分析，不引用单上文字里的数字和日期。三域都没有列出的单时结论说没有找到，不拿最接近的凑数。
   - 叫法统一为「相近的问题」。
   - 其余几种按文字找单（关键词、话题、点名字段、问做法）的模型同样拿到每域表格前 5 张的内容，点名时从中挑。
5. **查找说明**：一轮里只有按文字找单时，结尾那段叫「查找说明」。它写时间范围、查找范围（计入的域、未计入的域、已删除的单不查）、找法、筛选条件和其余相关的项，再加时效一句；不写计数单位。一轮里还有清单、统计、临时统计时照旧叫「统计口径」，各项照写。
6. **空行由程序统一放**：块与块之间一个空行，不用「；」加换行把几个域串成一段。
7. **段标题用三级标题，结尾前加一条分隔线**：开发者先看了两种写法的样例（粗体段标题、不加分隔线；三级标题段标题、结尾前加分隔线），2026-11-03 选后一种。一问多段时段标题（`### 1. …`）比各域小标题（粗体）高一级；统计口径或查找说明前的 `---` 把结论、明细与口径分开。代码里是 `present/layout.py` 的两个常量。
