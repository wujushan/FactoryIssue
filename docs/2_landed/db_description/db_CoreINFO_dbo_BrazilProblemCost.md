# BrazilProblemCost（巴西制程问题费用明细）

- **数据源别名（source）**：info
- **物理表名（table）**：CoreINFO.dbo.BrazilProblemCost
- **所属域**：巴西
- **用途**：问题单产生的费用明细。一张单通常按费用类型各占一行，多数为金额 0 的占位行；金额 0 的行上汇率也常为 0。
- **数据产生方**：INFO 系统巴西制程问题页面录入。
- **管理页面写法**：这张表在详情页上叫「涉案金额」，列为项目名称、金额（单位：雷亚尔）、汇率（美元兑雷亚尔）、金额（单位：美元）、备注说明，另有合计。单张单详情的费用表照页面的列名与列序给（备注一列仍叫费用备注，与按文字找单点名的字段同名）；「涉案金额」作同义说法。

## 字段

字段按单张单详情费用表的列序排。

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| ID | int | （内部字段，不返回） | 主键 | — |
| ProblemID | int | （内部字段，不返回） | 所属问题单 | `CoreINFO.dbo.BrazilProblemList.ID` |
| CostType | nvarchar | 项目名称 | 费用类型：物料费、第三方处理费用、物料报废处理费用、返工费、CIF税费、物流费、损失产能费用（停线） | — |
| CostBrlMoney | decimal | 金额（单位：雷亚尔） | 雷亚尔费用金额 | — |
| ConstBrlRate | decimal | 汇率（美元兑雷亚尔） | — | — |
| CostMoney | decimal | 金额（单位：美元） | 美元费用金额 | — |
| CostMemo | nvarchar | 费用备注 | 富文本 | — |

## 按单汇总

| 显示名 | 规则 |
|---|---|
| 费用美元合计 | 该单全部费用行的美元金额之和，空值按 0 |
| 费用雷亚尔合计 | 该单全部费用行的雷亚尔金额之和，空值按 0 |
| 专项费用明细 | 只拼美元或雷亚尔金额大于 0 的行，格式 `{费用类型}: {美元金额} USD / {雷亚尔金额} BRL`，行间用「；」；全为 0 时为空 |

汇率、备注只在费用明细里展示，不进合计。处理过程上的扣款费用（美元）是扣款 / 转嫁，与这里的专项费用合计分开，不相加。

「涉及费用的单」= 费用美元合计或费用雷亚尔合计大于 0 的单，按本表认定，不看主表「是否涉及费用」标记（见巴西业务描述「费用」）。
