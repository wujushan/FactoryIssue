# ZCTracking_PossibleInvCode（国内制程问题可能的问题物料）

- **数据源别名（source）**：info
- **物理表名（table）**：CoreINFO.dbo.ZCTracking_PossibleInvCode
- **所属域**：国内
- **用途**：建单时系统按问题类别和现象推荐的、可能涉及问题的物料。一单可多条。
- **数据产生方**：INFO 系统国内制程问题建单页面。
- **列类型**：按 information_schema（业务方 2026-10-22 内网元数据），字符串长度为声明的字符数。
- **数据现状**（业务方 2026-10-22 正式镜像计数）：全表 1,800 行，未删除的单上 1,653 行，涉及 295 张单，平均每张约 5.6 条。

## 字段

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| ID | int | （内部字段，不返回） | 主键 | — |
| ProblemId | int | （内部字段，不返回） | 所属问题单 | `CoreINFO.dbo.ZCTracking_ProblemList.ID` |
| InvCode | nvarchar(20) | 料号 | 物料编码，不可为空，原值展示 | — |
| InvName | nvarchar(255) | 物料名称 | 存单上的原值，不另查存货档案；可空 | — |
| InvStd | nvarchar(255) | 物料描述 | 存单上的原值；可空 | — |

## 怎么展示（与管理页面详情一致）

- 显示名「可能的问题物料」。逐条编号列出料号与物料描述，开头写明「根据问题类别和现象，系统分析的可能涉及问题物料」。
- 这是系统推荐的候选物料，不是这张单的涉及物料。按料号、物料名称查单只看主表料号，不看本表（见国内业务描述「物料」）。
- 以前的单可能没有，没有时不显示。
