# ProductName（产品 / 大机型）

- **数据源别名（source）**：info
- **物理表名（table）**：info.dbo.ProductName
- **所属域**：巴西、海外
- **用途**：产品（大机型）主数据，把大机型 ID 翻成名称与系列。
- **数据产生方**：INFO 系统产品主数据维护。
- **列类型**：按 information_schema（业务方 2026-10-20 内网元数据），字符串长度为声明的字符数。

## 字段（本模块用到的部分）

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| ID | int | （内部字段，不返回） | 主键 | 巴西 `BrazilProblemList.ProductIDAll`（逗号多值逐段匹配）；海外 `OverseasProblemDetail.ProductType`（逗号多值逐段匹配） |
| ProductName | varchar(50) | 大机型 | 产品 / 大机型名称，不可空。巴西、海外一单可多个，去重后用「、」连接。按大机型查时按完整名称匹配，不做包含匹配，见总述「三域共用的说法」 | — |
| Series | varchar(50) | 系列 | 产品系列，如 A920 属于 A 系列；可空。写法统一为「X系列」（如 A系列、IM系列、大S系列，不带空格），另有「其它」「底座」两个不带「系列」的取值（业务方 2026-10-21 正式镜像计数：目前每个产品都有系列）。巴西用户说「X 系列」时按本列查；海外不按系列查 | — |

表内另有编码、分类、在用状态、产品经理等字段，本模块不使用。
