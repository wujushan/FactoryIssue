# Employee（人员）

- **数据源别名（source）**：info
- **物理表名（table）**：info.dbo.Employee
- **所属域**：三域共用
- **用途**：员工主数据，把各表的员工 ID 翻成姓名，并经 `Unit` 得到所在部门。
- **数据产生方**：INFO 系统通讯录。

## 字段（本模块用到的部分）

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| ID | int | （内部字段，不返回） | 员工 ID | 各表的人员 ID 列 |
| Name | varchar(100) | 姓名 | 回答中按所在列的业务角色显示（如「问题跟进人」「填单人」） | — |
| Unit | int | （内部字段，不返回） | 所在部门 ID | `info.dbo.Department.ID` |
