# AfterSaleIssueClass（问题分类）

- **数据源别名（source）**：info
- **物理表名（table）**：CoreINFO.dbo.AfterSaleIssueClass
- **所属域**：巴西（停线级别）
- **用途**：售后 / 制程问题的分类主数据，含分类名称、各问题等级的不良率阈值和适用场景。本模块只在巴西域把它当作「停线级别」的名称表；海外不使用。
- **数据产生方**：INFO 系统分类维护页面。

## 字段（本模块用到的部分）

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| ID | int | （内部字段，不返回） | 主键 | `BrazilProblemList.ProblemClass` |
| ClassName | varchar | 停线级别 | 分类名称。回答停线级别时用名称，不用编号 | — |

表内另有分类类型、A/B/C 等级不良率上下限、适用场景（人工 / 客户 / 海外制程）与审计列，本模块不使用。
