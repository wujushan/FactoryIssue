# domestic_issue_vec（向量表，三域同族）

- **数据源别名（source）**：forge_mart_factory_issue
- **物理表名（table）**：public.domestic_issue_vec
- **表族（family）**：public.<域>_issue_vec（域 = domestic、brazil、overseas，即国内、巴西、海外）
- **所属域**：每域一张，国内为代表成员；三域结构相同
- **用途**：按意思找单（类似问题、涉及某个话题的「可能相关」那一组、点名比对范围内的字段时的按意思补充）。一段文字一个向量，只收参与按意思找的内容：国内问题现象、巴西海外的标准现象、剥净后不超过 10 个字的内容都不在里面（总述「比对范围」）。
- **数据产生方**：平台。按本助手声明的向量化规则建表，并按定时任务（每小时第 10、40 分钟）从本域按意思找的段表 `public.<域>_issue_vseg` 回填：只重嵌内容变了的段，段表里已没有的段连同向量一起删（决策 2026-10-20「G2 数据源与治理决策」「向量表」）。比治理任务晚约 10 分钟，按文字找单的时效见总述「命中后带回什么与时效」。
- **怎么读**：只经平台的语义检索（按本域向量表检索，按单限定候选、按栏目筛、按单去重），不做结构化取数。
- **权限**：表级，随所属域给「允许」；没有权限承载列。

## 字段（本模块用到的部分）

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| id | text | （内部字段，不返回） | 段编号，同按意思找的段表 `seg_id`：`<issue_id>:<字段代号>:<序号>`；主键 | — |
| content | text | 段落文字 | 段落文字，开头带栏目名；命中处的上下文与交给模型判断的文字取这里 | — |
| metadata | jsonb | （内部字段，不返回） | 回填时带进来的所属单与栏目，检索结果从这里取所属单 | — |
| issue_id | text | （内部字段，不返回） | 所属单，同文字表 `issue_id`；按单限定候选、按单去重用 | 文字表 `issue_id` |
| field | text | （内部字段，不返回） | 栏目代号，取值同分段表「字段代号」；按栏目筛用。分段规则为整单一段时记 `whole` | — |
