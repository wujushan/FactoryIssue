# tbIQCvendor（供应商）

- **数据源别名（source）**：info
- **物理表名（table）**：info.dbo.tbIQCvendor
- **所属域**：国内、巴西（海外的供应商名称直接取物料 JSON，不查本表）
- **用途**：供应商主数据，把供应商编号翻成名称。
- **数据产生方**：INFO 系统 IQC 供应商管理。

## 字段（本模块用到的部分）

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| fid | int | （内部字段，不返回） | 主键 | — |
| ferpcode | varchar(50) | 供应商编号 | ERP 供应商编码；空值不参与关联 | 国内 `VenCode`；巴西 `cVenCode` |
| fname | varchar(100) | 供应商名称 | — | — |
| ftype | varchar(50) | 供应商类型 | — | — |

表内另有地址、联系人、资质、准入分类、等级、删除标记等字段，本模块不使用。
