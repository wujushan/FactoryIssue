# tbTask（流程待办任务）

- **数据源别名（source）**：info
- **物理表名（table）**：info.dbo.tbTask
- **所属域**：国内（本模块只用国内制程问题的任务）
- **用途**：INFO 全公司共用的个人事务与待办任务表，一行是某人在某条业务记录上的一项任务。本模块只用它取国内问题单在效果确认、预防对策确认并行阶段（主表状态 30、36、37）的环节与处理人。
- **数据产生方**：INFO 系统各业务流程流转时写入。

## 取哪些行

国内问题单的任务：业务表名以 `ZCTracking` 开头，业务记录 ID 即国内问题单主表 `ID`（文本形式）。其他业务（含巴西制程问题）的任务不取。

当前待处理的任务：任务状态为「已接受」。

## 字段（本模块用到的部分）

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| fid | int | （内部字段，不返回） | 主键 | — |
| ftable | varchar | （内部字段，不返回） | 业务表名。国内制程问题的任务以 `ZCTracking` 开头 | — |
| frecID | varchar | （内部字段，不返回） | 业务记录 ID，文本型。国内制程问题任务存问题单主表 ID，如 `2824` | `CoreINFO.dbo.ZCTracking_ProblemList.ID` |
| fname | varchar | （内部字段，不返回） | 任务标题。国内制程问题任务固定为「国内制程问题单【单号】待××」，如「国内制程问题单【ZC2609022】待效果确认」；取「】待」之后的文字作为处理环节（「效果确认」「预防对策确认」） | — |
| fuserID | varchar | （内部字段，不返回） | 任务对应人员，单个员工 ID（文本型，需转整数关联）；多人时每人一条记录 | `info.dbo.Employee.ID` |
| fstat | varchar | （内部字段，不返回） | 任务状态：待接受、已接受、已接收、已完成、完成、已取消；另有业务码值 `326` 与一个历史遗留的说明文字取值。本模块只取「已接受」 | — |

派生显示：处理环节（取自任务标题）、处理人（人员 ID 经人员表翻成姓名）。
