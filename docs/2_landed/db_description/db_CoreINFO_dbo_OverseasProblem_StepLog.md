# OverseasProblem_StepLog（海外制程问题处理步骤）

- **数据源别名（source）**：info
- **物理表名（table）**：CoreINFO.dbo.OverseasProblem_StepLog
- **所属域**：海外
- **用途**：问题单流转的处理步骤日志，记录每个环节的操作人、操作时间、类型、结论、意见、内容与附件。
- **数据产生方**：INFO 系统海外制程问题流转时写入。
- **两种读法**：同一问题单（`ProblemId`）的同一步骤名称（`StepStr`）会有多条。完整处理过程把它们全部列出，按 `Id` 升序排，驳回前的旧记录、每一次驳回与任务转移都给，与管理页面「操作记录」一致（决策 2026-10-23「操作记录显示全部记录」）。查看某一环节时只取 `Id` 最大的一条。两种读法都与国内相同。
- 按文字找单时只比对分析类环节、每个环节最新一条的意见与内容（工厂制程分析另含结论），环节清单见总述「比对范围」。
- 步骤上的成员是该步骤节点的处理人，不用它代替主表的当前责任人。
- 单张单详情里：「结案确认」的意见显示为「结案结论」；「效果确认」的意见与主表效果确认内容相同，页面标签为「效果确认结果」（见海外业务描述「单张单详情」）。结案确认这一步的结论都为空，意见与内容都有值（业务方 2026-10-23 正式镜像计数：10 张单）。
- **派生：结案时间**：只对主表状态为「已完成」的单定，取该单 `StepStr` 为「结案确认」、`Id` 最大的一条记录的 `AddDate`，显示名「结案时间」。没有这样的记录时定不出结案时间，按结案时间筛选、统计时不计入（见总述「结案时间与结案周期」）。个别已完成的单没有「结案确认」记录（见 `dirty_data.md`「其他」）。

## 字段

| 字段 | 类型 | 用户可见显示名 | 含义与取值 | 关联 |
|---|---|---|---|---|
| Id | int | （内部字段，不返回） | 主键 | — |
| ProblemId | int | （内部字段，不返回） | 所属问题单 | `CoreINFO.dbo.OverseasProblemDetail.Id` |
| Step | int | （内部字段，不返回） | 步骤序号 | — |
| StepStr | varchar | 类型 | 步骤名称。管理页面「操作记录」的列名是「类型」；在回答正文里也可以叫「处理环节」。现有取值：填写问题、指定责任人、责任人确认、任务转移、IQC填写意见、SQE跟进、修改问题、工厂制程分析、驳回、效果确认、结案确认（业务方 2026-10-23 正式镜像计数） | — |
| ProblemStatus | int | （内部字段，不返回） | 该步骤时问题单的状态码，枚举同主表 `Status` | — |
| MemberList | varchar | （内部字段，不返回） | 该步骤成员 ID，逗号分隔。管理页面不展示，处理过程不给这一列；谁处理的看操作人 | `info.dbo.Employee.ID` |
| Result | nvarchar | 结论 | 只有工厂制程分析环节是文字，原样展示。SQE跟进存 0 / 1，与国内一致：0 = 不需要设计变更，1 = 需要设计变更（目前只有 0）。其余环节为空。处理过程不单列 | — |
| Opinon | nvarchar | 意见 | 处理过程里只在内容为空时顶替内容；单张单详情里各环节另有标签 | — |
| Measures | nvarchar | 内容 | 系统按这一步的操作拼好的一句话：操作人姓名，加上这一步的结果与所填各项（如责任人确认的确认结果、处理结果、改善措施、预防对策、原因分析），与意见、主表同名字段有重复。管理页面「操作记录」的「内容」列，与国内处理步骤同一含义。驳回这一步的内容写明驳回说明，形如「驳回任务,驳回说明:…」 | — |
| DocID | varchar | 附件 | 该步骤附件的文档 ID，逗号分隔；以文档名称展示，ID 不外露 | `info.dbo.DocumentList.ID` |
| AddUser | int | 操作人 | 做这一步的员工 ID，翻成姓名。不叫「创建人」：用户说「创建人」指填单人（见海外业务描述） | `info.dbo.Employee.ID` |
| AddDate | datetime | 操作时间 | — | — |

## 处理过程怎么展示

照管理页面「操作记录」，与国内相同，给 5 列（业务方 2026-10-23 管理页面核对）：

| 列 | 取什么 |
|---|---|
| 操作人 | 做这一步的人，翻成姓名 |
| 操作时间 | 这一步的时间 |
| 类型 | 环节名称 |
| 内容 | 内容列；为空时取意见 |
| 附件 | 以文档名称展示，已删除的不展示 |

- 结论、意见不单列：内容本身已把这一步的结果与所填各项写成文字。
- 全部记录都列，按 `Id` 升序（见上文「两种读法」）。
