# 权限管控

## 按域授权

三个域分别授权。用户对某一域没有权限时，该域不出数；有权限的域照常查询与汇总。三域一起查时，无权限的域在回答中明说「无权限，未计入」，不说成「没有数据」。

| 域 | 受管控的主表 | 有权后域内可见范围 |
|---|---|---|
| 国内 | CoreINFO.dbo.ZCTracking_ProblemList 及其子表 | 全量，无行级、列级管控 |
| 巴西 | CoreINFO.dbo.BrazilProblemList 及其子表 | 全量，无行级、列级管控；不按工厂、部门、个人再切可见性 |
| 海外 | CoreINFO.dbo.OverseasProblemDetail 及其子表 | 全量，无行级、列级管控 |

人员、部门、工厂、物料、供应商、文档等主数据表随所在域的查询一起使用，本身不单独作为域闸门。
