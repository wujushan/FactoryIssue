# 业务术语表

> `manifest.glossary` 的唯一信源；改本文件须同步 `src/factory_issue_module/module.py` 的 `glossary`。

| 规范词 | 别称 | 口径定义 |
|---|---|---|
| 制程问题 | 制程单、制程问题单、制程相关问题 | 生产制程中发现并登记的质量问题单。不指某一种问题类型 |
| 国内制程问题 | 国内、ZC 单 | 国内工厂的制程问题，单号 `ZC` 开头 |
| 巴西制程问题 | 巴西、BR 单 | 巴西工厂产线上的制程问题，单号 `BR` 开头 |
| 海外制程问题 | 海外、HW 单 | 海外工厂的制程问题，单号 `HW` 开头 |
| 问题编号 | 单号、制程单号 | 「前缀 + 年月 + 3 位序号」，如 ZC2109001 |
| 加工厂 | 工厂 | 问题发生的工厂：国内为国内工厂，巴西为巴西工厂名称，海外为海外工厂名称 |
| 国内工厂 | — | 海外单上另记的国内工厂 |
| 大机型 | 产品、机型名称列表 | 产品主数据中的产品名称（巴西、海外） |
| PN | 机型编码、PN 列表 | 机型编号。国内看生产订单上的 PN 与 PN 名称；巴西经关联申请单解析、一单可多个，海外存在主表上，两域都经 PN 主数据翻成名称展示，按 PN 查时名称或编码任一命中；海外发货单上的 PN 用发货单自己的编号。与物料料号不是同一套编号 |
| 机型 | 机型名称、机器型号 | 具体终端产品型号，常为「字母 + 数字」简写，如 A920、Q92、IM30。国内来自机型子表，巴西、海外来自大机型（不按 PN）；跨域按机型汇总时同名合并 |
| 系列 | — | 机型所属系列 |
| 料号 | 物料编码、物料编号 | 物料的编码，经存货档案翻成物料名称与规格型号 |
| 停线 | 曾经停线、发生过停线、有停线记录 | 曾经停过线，已重启的仍算 |
| 停线中 | 目前停线、正在停线、停线且未重启 | 当前仍处于停线、尚未重启。国内含重启审核、审核通过、填写重启方案 |
| 停线重启 | 已重启、已恢复生产 | 停线后已经重启 |
| 结案 | 已结案、已完成、关闭 | 国内、海外为「已完成」，巴西为「已结案」 |
| 未结案 | 进行中、没完成、未关闭 | 尚未到达该域的结案完成状态 |
| 问题跟进部门 | 跟进部门 | 被指定跟进处理问题的部门 |
| 问题跟进人 | 跟进人 | 被指定跟进处理问题的人员 |
| 当前处理人 | 当前谁在处理、当前责任人 | 问题单流转到最新节点时的处理人（国内、海外）。巴西不提供，问到时给问题跟进人 |
| 责任归属部门 | 责任部门、定责部门、定责 | 国内结案后人为定责的部门。巴西没有，按问题跟进部门理解 |
| 原因分类 | — | 国内结案时人为归类的原因，从固定列表选取，如「人为工作疏忽」 |
| 产品在制属性 | 订单类型、生产阶段 | 国内单关联的那次生产所处阶段：首次量产、首次量产爬坡、正常量产、量产爬坡、未释放 PN、物料试产、小批量试产、工程样机 |
| 投诉单号 | Claim、CLAIM 单号 | 巴西单上的投诉单号，自由文本，多数以 CLAIM 开头 |
| 费用 | 专项费用 | 巴西单产生的费用明细，按美元、雷亚尔分别合计；与扣款费用分开 |
| 扣款费用 | 扣款、转嫁 | 巴西处理过程上的扣款金额（美元），不是专项费用合计 |
| 补料 | — | 巴西单是否需要补料、补料数量与结果 |
| 雷亚尔 | BRL、巴西币 | 巴西货币 |
| 现场发现日期 | 发现日期 | 现场发现问题的日期，区别于建单时间 |
| 建单时间 | 填单时间、提交时间 | 制程单填写并提交的时间 |
| 统计日期 | — | 巴西单上的统计日期。只有用户明说「统计日期」时才按它筛选，否则按建单时间 |
| 不良率 | — | 国内取单上百分数；巴西 = 不良数量 ÷ 影响数量；海外按单上原文 |
| 问题等级 | 等级 | 国内、巴西 A/B/C，海外 A+/A/B/C |
| 停线级别 | — | 巴西停线的级别名称 |
| CAR | 纠正预防措施单、纠正预防措施报告 | 国内物料问题关联的 IQC 纠正预防措施报告，含根本原因、永久纠正措施、预防措施、有效性确认 |
| 8D | 8D 报告 | 巴西问题单需回复的 8D 报告。「是否需要回复 8D」与已上传的 8D 文件是两件事 |
| IQC | 来料检验 | 来料质量检验；IQC 意见为退回仓库或继续使用 |
| SQE | 供应商质量工程师 | 供应商质量跟进与确认环节 |
| SQC | — | 国内状态「SQC跟进」环节 |
| PMC | 生产物料控制 | 国内状态「PMC确认」环节 |
| 小板订单 | 小板生产任务订单 | 国内中间产物（物料标识为「物料」）的生产任务订单 |
| 其他在线订单 | — | 国内问题单关联、受影响的其他在线生产订单；整机单与「物料」单都可能有 |
| 物料标识 | 中间产物 | 国内单标「物料」表示问题出在磁头、面壳组件等中间产物而非整机 |
| 问题现象 | 缺陷现象、不良现象 | 巴西单上的现象（展平成一段文字）；海外为「已选问题现象」；国内写在问题描述里 |
| 已选问题现象 | — | 海外单勾选或手填的现象，一单可多条 |
| 可能问题原因 | — | 海外标准现象下可供选择的原因清单，不是单上写下的原因分析 |
| 问题原因 | 原因分析 | 单上已经写下的原因 |
| 类似问题 | 相近问题、类似案例、有没有出现过 | 按现象描述找意思最相近的问题单，默认最多 10 张，不保证完整 |
| 关键词搜索 | 搜索、含有、描述中有 | 找出文字里出现指定词的全部问题单；「和」都出现，「或」出现任一 |
| 非接 | 非接触 | 非接触式读卡相关问题，按现象文字查找 |
| 涉及发货单 | 发货单 | 海外单涉及的发货单，含 PO、发货单号、日期、PN、版本、数量 |
| 处理过程 | 处理步骤、完整处理过程、流转记录 | 问题单走过的各环节记录：环节、处理人、意见、措施、结论、时间 |
| 责任人处理结果 | — | 国内工程确认环节措施里「处理结果：」之后的文字 |
