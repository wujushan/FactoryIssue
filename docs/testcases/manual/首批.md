# 首批人工测试手册（33 条）

输入是种子 v0.9.5 里状态为 baseline 的 33 条。自动化断言在 `docs/testcases/golden/cases.json`，参考 SQL 在 `docs/testcases/golden/sql/`。

写法按《G3写作约束》：一条只考种子里那个变量；数字按口径，不写某天的张数；不把表张数、列顺序、调用次数、事件顺序写成断言。

占比这一列的表头按总述「回答怎么组织」写「占比（%）」。种子呈现里写的是「占比」，指的是这一列。

失败时先看四层：没进本模块是路由（这些用例都带了目标模块，正常不会是这一层）；没取数或取数范围错是取数；张数、分组、单号集合不对是口径；表头或正文出现表名、字段名是呈现。
