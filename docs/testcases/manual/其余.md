# 其余案例（82 条 golden + 5 条权限手册）

首批 33 条见 `首批.md`。这里是种子里其余的案例。权限 5 条只有人工步骤，没有自动化断言。

多轮案例先发「前置一轮」，再发本条问句。断言只看后一轮。

## CN-002 责任部门

- 级别 / 形态 / 取数 / 验证：P1 / 清单 / 结构化 / A
- 问句：2025 年国内有多少起软件问题？把每张单的责任部门列出来
- 前置：—
- 期望行为：时间 2025 全年、类型＝软件问题；责任部门按「责任归属部门」（结案后人为定责，可多个、逗号多值逐段匹配），不是问题跟进部门；为空时已完成的单写「无需定责」、未完成的单写「未定责」，部门关联不上写「未填」。
- 数据断言：2025 全年、软件问题。责任部门是责任归属部门。已完成且为空写无需定责，未完成且为空写未定责，部门对不上写未填。
- 呈现断言：表含问题编号、责任归属部门。开头给总数。统计口径写明按责任归属部门。
- 不写什么：不查问题跟进部门。不写死张数。
- 失败分层：跟进部门被当成责任归属部门→口径。
- 参考 SQL：`docs/testcases/golden/sql/CN-002.sql`
- 种子备注：两口径混淆是这条的考点；物料问题不按责任部门统计（这条是软件问题，不受影响）。；与 CN-024 区别：本条是 2025 软件问题清单，另条是 2026 上半年责任部门统计。

## CN-006 时间+停线
