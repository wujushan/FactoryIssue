## 使用顺序

1. 执行 `种子命中复核.sql`，把结果填回工作簿「种子复核」页，v0 升 v1；
2. 业务方补「非接、音频」等话题的应命中集；
3. 替换 12 条占位符（真实单号/人名/CAR/CLAIM/发货单号）；
4. G4b 按「验证方式」列做 B 类单测夹具（不落库）；
5. G3 写作前先读 `G3写作约束.md`，逐条过评审八问；
6. 三方评审后冻结 v1.0，再进 G3。
