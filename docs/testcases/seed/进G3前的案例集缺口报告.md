## 附：断言词表（G3 写 golden 时统一用）

| 断言 | 用在哪种结果形态 | 例子 |
|---|---|---|
| 表列包含 | 清单/详情/统计/查单 | 列里必须有「问题编号」「不良率」 |
| 表列不得出现 | 全部 | 不得有 `ID`、`IsDelete`、`ProblemType` |
| 行数 ≥ N / = N | 清单/详情 | 详情 1 行；清单至少 1 行 |
| 数值关系 | 统计 | 合计=分项之和；分域小计之和=总合计 |
| 正文包含 | 全部 | 「统计口径」「问题本身涉及」「处理中提到」 |
| 正文不得包含 | 全部 | `dbo.`、表名、字段名、自增 ID、`0.0` 占位 |
| 图表 | 统计 | 至少 1 张、类型在 [pie,bar,line]、点数≥3 |
| 澄清 | 澄清 | clarify 非空；query_count=0 |
| 不取数 | 寒暄/只读/格式错 | query_count=0 |
| 链接 | 查单/详情/导出 | 正文含可点的单号/CAR/下载链接 |
| 建议按钮 | 寒暄/澄清/统计后 | suggestions ≥2，每项含 id/name/label/query |
